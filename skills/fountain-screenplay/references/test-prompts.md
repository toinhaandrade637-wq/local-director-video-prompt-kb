# 怎么测 Fountain skill + 预览

在普通对话任务里打开工作区，新建或打开 `.fountain`（不要用 `.md` / `.txt`）。内置 skill `fountain-screenplay`（展示名「专业剧本格式」）在点名专业剧本格式 / `.fountain`、或「新建一个剧本」这类建稿意图时被选用。Agent **没有**剧本私有工具，只应调用 `read_file` / `edit_file` / `write_file`。

命中走 `name` + `description`，不走 `displayName`。未指定格式的「写剧本 / 改剧本」默认不是本技能。

下面每条：先把种子写进文件（或让 Agent 按这段写），再把提示发给对话。核对预览面和磁盘源码面。

## 0. 该不该加载本 skill

**应命中（正例）**

```

```

```

```


## 1. 新建一集（信息区 + 空场）

**提示**

```
在工作区新建 第3集.fountain。按 Fountain 写：Title 重生之还是她，Episode 第3集，Logline 她发现当年的手术其实没做完。正文从一场空的中文场次头开始：内景. 医院-走廊 - 夜。不要写成 Markdown。
```

**期望**

- 磁盘开头是 `Title:` / `Episode:` / `Logline:`，空行后才是 `内景. 医院-走廊 - 夜`
- 预览顶上信息区能读到剧名/集数/一句话；场次控件是 1 / 夜 / 内 / 医院 - 走廊
- 源码面没有 `△`、没有 JSON、没有 `# 标题`

## 2. 补一场戏（os/vo、空角色、字幕、转场）

先有上面的文件，再发：

```
接着写。走廊里护士推车过去。张三os内心：别回头。李四：（低声）跟我走。然后字幕「三年后」，CUT TO: 下一场内景. 客厅 - 日，时间继承夜改成日、地点换成客厅。角色名用 @张三os / @李四，不要写成 (V.O.)。
```

**期望**

- `@张三os` 与 `@李四` 分行；括注是 `(低声)`；字幕是 `【字幕：三年后】`
- 预览：张三一块台词，os 三态为 os；李四有情绪（短剧口径关掉时预览藏括注，源码仍在）
- 好莱坞切换：两人声音都显示 `(V.O.)`，源码仍是 os / 人名，没有被改成 `(V.O.)`

## 3. 改错格式（skill 该修的）

把文件故意写成：

```
# 第一场
张三
别过来。
字幕：三年后
张三 (V.O.)：走吧。
```

**提示**

```
这个 fountain 预览全乱了，按 WorkRally 的 Fountain 规则改成能定类的源文件。中文名要加 @ 或写成 人名：台词；字幕用【字幕：】；不要把旁白存成 (V.O.)，用张三os。
```

**期望**

- `# 第一场` 变成场次头（`内景. …` 或强制点），不是动作
- `张三` 单独一行不再当动作
- `【字幕：三年后】`
- 旁白是 `@张三os` 或 `张三os：`，不是 `(V.O.)`

## 4. 闪回 + 人物表（导出）

```
在客厅这场后面加一场闪回：内景. 仓库 - 夜 （闪回），只有一句动作「伞还在滴水」。不要给闪回编 sceneId。然后告诉我中文 Word 里人物列表和闪回标记会是什么样（不必真的去点导出，除非我要求）。
```

**期望**

- 磁盘场次行带 `（闪回）`
- 预览场号 1A，闪回开关亮
- Agent 说明 Word：场次下有 `人物：…`，闪回场前后 `【闪回】` / `【闪出】`；不要发明 JSON 字典

## 5. 不要做的（反向）

```
把这个剧本存成规范 JSON Schema，带 characterRegistry 和 sceneId，再用 BlockNote 打开。
```

**期望**

- Agent 拒绝改存储格式，继续改 `.fountain` 纯文本
- 不会去读拉片 Agent 的 `screenplayScenes`

## 手工点预览（不经过 Agent）

| 操作                                   | 期望                                                 |
| -------------------------------------- | ---------------------------------------------------- |
| 光标在第一场场次头，插入菜单选「台词」 | 标题还在，下面多一块空台词                           |
| 第一场场次头按 Tab                     | 还是场次头，不变成动作，也不会从时间跳到内外景       |
| 时间框光标在末尾按右键                 | 跳到内外景；上下键才改日夜                           |
| 地点框输入「酒」                       | 能看到「酒店」和「酒店-大堂」这类组合                |
| 新建场次 / 点空场次头                  | 光标在时间框，下列表；上下键改日夜，Enter 跳到内外景 |
| 第二场空角色框聚焦或悬停               | 本篇说过的名字在上面                                 |
| 删光唯一一场的地点再 Backspace         | 仍留下一场空场次头，不会变成一篇纯动作               |
| 信息区四框留空保存                     | 磁盘没有 Title 键                                    |
| 场次轨拖一条到另一条上                 | 整场（场次头到下一场之前）一起走，场号按新顺序       |
| 把已出现过的角色名改成新字再失焦       | 弹出全篇同步 / 只改本处；点补全列表换人则不弹        |
| 侧栏「待补」点一条                     | 跳到对应场次或空名台词；空角色框不出现在待补里       |

## 6. 改名（磁盘替换）

**提示**

```
把全篇角色「张三」改成「陈默」，地点「客厅」改成「起居室」。只改 Fountain 文本，不要写 JSON。
```

**期望**

- `@张三` / `张三：` / `张三os` 都变成陈默；`张三丰` 这种更长的名字不要误伤
- `内景. 客厅 - 夜` 变成 `内景. 起居室 - 夜`；`酒店-客厅` 这种父级不是「客厅」的不要改
- 没有 characterId / 角色字典

## 7. 挪场

先有客厅、仓库两场，再发：

```
把仓库那场整场挪到客厅前面。场号让预览自己编，不要手写 1、2。
```

**期望**

- 磁盘上仓库场次头及其后直到下一场的内容出现在客厅之前
- Agent 不发明 sceneId，也不把闪回拆出独立容器

## 8. 待补与导出说明

```
看看这份 fountain 预览会标哪些待补。然后告诉我：如果切好莱坞并打开短剧口径再导出 Word，人物列表和连续同角色括注会怎样。不要改存储格式。
```

**期望**

- 指出：有台词没人名、空地点、未识别的时间/内外景；空 `@` 不算待补
- Word：好莱坞不写 `人物：`；短剧口径下连续同角色只留首个括注
- 拒绝 JSON Schema / BlockNote

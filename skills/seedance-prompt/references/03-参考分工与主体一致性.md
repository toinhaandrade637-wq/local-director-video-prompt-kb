# 参考分工与主体一致性

先确定内容怎样发生，再分配文字、图片、视频和音频各自提供的信息。同一内容可以采用不同输入方式，正文始终围绕最终人物、动作与空间展开。

## 短摘录：视频管动作，图片管最终形象

P024《绿色西装独轮车》的两处原文：

> @Video 1 defines ONLY the exact 30-second action and editing blueprint: shot order, cut timing, downhill route, rider trajectory, stunt timing, camera positions, tracking paths, lens changes, foreground wipes, speed changes and audio rhythm.

> @Image 1 is the canonical identity, fashion, unicycle, environment and color reference.

**好在哪：**第一句把视频的职责落到镜序、路线、动作时机、摄影和节奏；第二句把最终人物、服装、独轮车、环境和色彩交给图片。写作时先做这一步，后文就可以明确围绕“绿色西装男子骑独轮车”展开，而非混用原视频中的人物或自行车外形。

## 把每份素材的职责写清

| 输入 | 写清什么 |
|---|---|
| 人物或全身图 | 对应谁的面貌、造型与比例；多图是否属于同一角色 |
| 道具图 | 结构、材质、外观；持有者和交接过程在动作段展开 |
| 场景图 | 采用哪些地形、建筑、材质、光线与空间关系 |
| 站位或构图图 | 标记对应谁，机位朝向与前后层次怎样组织 |
| 视频 | 采用的动作、路线、节奏、镜头；被新素材替换的属性 |
| 音频 | 对应角色，采用音色、发音或其他指定属性 |

编号在当前这组提示词内对应明确对象。跨组工作时重新列映射，正文可同时使用稳定角色名方便阅读。构图示意中的色块、人物身份图、首尾画面图各承担自己的任务。

## 一致性留住什么，过程又改变什么

身份在转身、裁切、遮挡和表情变化中保持；衣物保留造型，同时响应步伐与受力。世界站位、身体朝向、头部视线和当前画幅位置分别交代。固定人物总数时，每镜可按观察需要选择入画者。

用“强调！”突出当次必须保持的属性和覆盖时段。任务要求首帧或尾帧匹配时，明确指定对应画面；普通人物、道具或场景参考主要承担其属性。P052有明确首尾画面要求，P024的图片则用于整体视觉参考，两种写法各有用途。

“承接末帧”进一步说明接的是画面、动作状态，还是已有视频的实际延长。动作接续允许换景别，画面匹配则需要顾及同一接点的构图；提交时再对应平台的输入角色。

## 参考改变后，补齐文字承担的信息

P024已有完整路线、动作与摄影描述，适合继续完善为图像参考或文生版本。移除视频，就把原先仅由视频承担的过程补进正文；移除图片，就补足已经确定的外观与空间。把自行车换为独轮车后，踩踏、起跳、着地和平衡也按独轮车结构组织。

改稿先确认本次采用的版本和时段，保留有效内容，解决参考职责的冲突，再处理重复。这样输入方式可以变化，人物和事件仍是一套清楚的当前方案。

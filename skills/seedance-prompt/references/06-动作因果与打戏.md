# 动作因果与打戏

把动作写成能接着发生的过程：**当前条件 → 行动 → 接触或作用 → 应对 → 新状态 → 下一步。**起身、搬运、道具交接、运动和攻防都可以从这条关系展开，细写其中决定结果的部分。

## 先写力从哪里来

接触动作选择关键支撑点、持握、重心、施力方向和受力结果。攀爬要看清抓握与落脚，扶架起身要接住跪姿和双脚承重，搬运要看见合力怎样克服阻力。身体、道具和接触面放在同一个动作小段里。

**短摘录｜P033，掌击之前的发力**

> 图1突然用左手将图3向自己方向猛拉。她左脚固定承重，左膝轻微下沉；右脚前掌蹬地，右脚跟自然抬起并向内旋转，髋部带动腰、右肩和右臂向前。

**好在哪：**“猛拉”先改变双方距离；左脚承重、右脚蹬地、髋肩带动，给接下来的掌击建立了连续发力链。写这类动作时，先选出真正决定力量和方向的几处接点，再接命中后的衣料压陷、身体位移与余摆。如此能把“有力”落实成身体过程。

同一动作换镜头时接进度。P040在逃跑刚启动时切走，追摇找到时动物已在跑；P045的道具依次经历夺取、试用和归还，每镜接当前持有者。关键关系可以连续拍，也可以用明确的动作接镜呈现。

## 每次应对都改变战局

先问对手从哪里攻击什么，再写主角怎样换位、拦挡、改招或改变目标；接触后交代双方位置和武器状态，让下一招有条件发生。复杂打戏重点展开关键交锋，其他动作可以概括，但每段要留下战局进展。

组合技可以通过聚拢、束缚、暴露缺口、追击或能力转化衔接。有效反扑会改变主角接下来做的事；主角即使保持不受伤，也能被迫换路线、收回一招或重新找支撑。恢复与蓄力可以融在移动中，节奏按这场戏的要求决定。

遇到P030、P032、P035这类招式与特效密集的材料，先把“谁先做什么、另一方如何回应、局面改变在哪里”理顺，再选保留的招式。原材料中可取的局部机制与用户指出的整体问题分别吸收。

## 把特效接在作用过程上

写清发动者、起点、载体或路径、目标、接触结果和残留。P033依次呈现发力、衣料受压、身体反应、能量扩散、灵体错位，再用试触确认新状态；特效和表演沿同一事件前进。

武器变形时接住碎裂、凝聚、持握与再攻击的状态；空间法术则交代真实朝向和摄影机看到的方向。颜色、密度和规模用来组织视觉主次，命中、位移与结果负责把作用讲清。已经产生的破坏、位置和残留，继续成为下一步的条件。

## 让动作可读，再安排速度

区分主体移动、相机运动和播放速度。动作量按支撑转换、接触、反应与观察所需时间安排；有些步骤并行，有些必须先后完成。持续运动可以是一条动作的延续，也可以是连续攻防，按当前观看任务取舍。

# Seedance 2.5 提示词编写

先读[用户约定](references/01-用户约定.md)和[通用结构](references/02-通用结构与选用.md)，理解当前任务，再选相关方法及短例。例子用来学习组织关系和笔法，成稿使用本次的角色、事件与素材。在知识库内工作时，优先读取现行知识目录中的同名最新页；独立使用此Skill时读取随附references。

## 把内容写成画面

共同骨架：**生成目标或一句话概述 → 必要参考分工与全局设定 → 镜头／阶段中的综合小段 → 结束状态与必要约束。** 依内容决定展开程度。

开头交代这段发生什么、以何种方式观看。参考图、视频和音频各自负责身份、造型、场景、构图、动作、节奏或声音，要对应到明确对象。参考方式改变时补齐失去的视觉或运动信息。

全局写共同条件和本场发展。正文按观看顺序，把刺激或决定、人物动作与目的、可见表演、摄影关注点，以及相关的环境光声联在一起。近景细写目光和话语交接，动作段写支撑、受力与结果，转场写保持项、变化过程与到达状态。一个镜头可以有多个节拍，一镜到底可以分阶段。

细节写到关键过程可以辨认。先看本页短例中的措辞为何有效，再迁移到当前事件：人物怎样动、摄影怎样跟、环境怎样回应、下一镜接住什么。保留用户已有的好组织方式，选用综合段落或本镜正文加光影／现场声。

## 改稿与交付

沿用已确定的剧情、人物、台词、风格和结束状态。修改时把问题落实到原来的段落；只要求分析时，给具体问题和局部改法。缺少影响身份或关键接续的信息时，明确列出缺口，同时完成能处理的部分。

交付前读通动作与对白进度、可见性、空间方向、道具归属、光声和时间容量。合并无新增作用的复述，保留证明接续或变化的细节。重要要求用“强调！”后接对象、属性和时段；首帧匹配、音乐、画幅和慢动作等沿用当前任务选择。

成稿以可直接使用的提示词为主体，必要时附简短说明。日常查询与写稿直接使用现行方法和示例，知识维护由批次学习另行处理。

# KOK BÖRÜ 完整版全流程创作方法论

> **依据**：对 Higgsfield 官方 15 分钟动画长片 KOK BÖRÜ 完整版（KOK_BORU_FILM，14,021 资产）的全量逆向——19 个文件夹（三幕 15 场戏）全部抓到游标尽头，去重后 12,052 个 job、12,052 条提示词（2,421 条唯一）逐类精读。
> 与节选版（02 区已存的 KOK_BORU，2,781 资产、218 条唯一）互补：**节选版是英文体系 + DIRECTOR'S NOTES；完整版是中文体系 + 【标签】语法**——同一部片的两种生产语言，放在一起构成完整证据链。

## 〇、项目画像

**故事**：悲痛的草原母亲发现多年前被狼群夺走的女儿还活着——由村庄要消灭的狼群养大。两个母亲（一个女人、一只母狼）被同一个失踪孩子相连。15 分钟三幕结构（ACT1 SC01-09 / ACT2 SC10-13 / ACT3 SC14-15）。

**规模**：14,021 资产 = 节选版的 5 倍；**中位提示词 9,207 字符**（全工作区最高之一，最长 37,751）。

**时间线**：2026-06-25 ~ 07-17（23 天密集生产）。

**模型**：seedance_2_0 ×11,657（绝对主力，与节选版相同——定格动画的帧率在后期做，视频模型只需出平滑）+ text2image_soul_v2 ×152 + seedream_v5_pro ×100。

**语言分布**（重大发现）：**中文 1,981 / 英文 407 / 俄语 33**——与节选版（英文为主）相反，**完整版 82% 用中文生产**。

**视觉 DNA 六要素**（词频来自 2,421 条唯一提示词）：

## 一、中文【标签】体系（完整版的核心语法）

完整版用中文【标签】替代了节选版的大写英文段落。段落标签 TOP：风格＝绝对最高优先 / 导演笔记 / 音频 / 空间地理 / 约束Constraints / STORY CONTEXT剧情背景 / COLOR INTEGRATION / DEPTH OF FIELD景深 / WIND夜风 / DETAIL HIERARCHY / 表面质感＝反光滑铁律 / 活体清单 / 这是动画片＝第一前提。

**方法论**：
1. **【风格＝绝对最高优先】开场**——等号语法直接写优先级（中文比英文 `ABSOLUTE HIGHEST PRIORITY, READ FIRST` 更紧凑）
2. **双语混搭标签**：【约束Constraints】【STORY CONTEXT剧情背景】【WIND夜风】——中英对照标签，团队两种语言都能索引
3. **声明式标签**：【空间地理＝锁定、绝不跳轴】【这是动画片＝第一前提、优先于一切】——标签本身携带规则
4. **【活体清单】×150**——动物大场面（狼群/羊群/鹰）的人数锁：清单化列出画面中每个活物

## 二、范本引用的中国式写法（35,209 字范本）

    【风格＝绝对最高优先】本片全部画面的绘画技法、笔触、造型语言、表面质感、
    渲染方式，一律严格以 <<<b5cd974b...>>> 为唯一权威范本——完全照搬它的画法：
    大而概括的平面化笔触、用大色块塑造形体、简洁有力的剪影、概括而不琐碎的
    细节、沉稳压抑的电影感色调。**每一个色块内部都保留那种可见的笔触方向与
    手绘边缘——色块之间是画出来的、有笔触的交界，绝不是数码渐变、绝不是光
    滑无笔触的平涂填色；夜色与暗部同样由可见的平面笔触画成，绝不因黑暗而
    变成光滑的深色渐变。**...只从它取"怎么画"（技法/笔触/造型/质感），
    不从它取它的具体颜色、光照方向或场景内容。

**三点独门**：
1. **"怎么画"与"画什么"分离**：从范本取技法不取内容——比英文版的 controls 声明更彻底
2. **反负面词召唤**：不是厚涂堆叠、不是刮刀肌理、不是定格黏土、不是3D、不是照片写实、不是廉价AI感——**六个"不是"穷举错误方向**（正面定义之后负面钉死）
3. **暗部笔触条款**：夜色与暗部同样由可见平面笔触画成——**最容易被模型"光滑化"的暗部被单独点名**

## 三、"先钢后声"的段落节奏判词

SC12 警号段（官方原文）：
> 【警号＝本段第一法则】前一段是绷到极限的静——**本段是弦断的一声：先是钢、后是声。**（一）**拔刀：一个短促、凶狠、纯实战的出鞘**——手掌拍上腰间刀鞘、一把将猎刀抽出：轨迹低、平、贴身，钢一离皮革就沉向大腿一侧、落进战斗握持（刀尖朝前下方）——半秒的钢、没有仪式、没有挥舞、没有向上的大弧、绝不举刀、绝不亮相：**像猎人抽出工具、不像英雄拔出圣剑。**

**方法论**：
- **段落级节奏判词**：每段戏标注自己的第一法则（"先是钢、后是声"）
- **动作的文化修辞**：拔刀不是武侠亮相而是猎人取工具——**动作语义用文化比喻锚定**（这是 KOK BORU 与 CHB 的 b-boy 竞技场语法同理：动作的"身份"决定它的形态）
- **"绝不举刀、绝不亮相"**：负面动作清单再次出现

## 四、与节选版对照（同一部片的两种生产语言）

| 维度 | 节选版（KOK_BORU） | 完整版（KOK_BORU_FILM） |
|---|---|---|
| 规模 | 2,781 / 218 唯一 | **14,021 / 2,421 唯一** |
| 语言 | 英文为主 | **中文 82%** |
| 段落语法 | 大写英文段（SCENE CONTEXT / DIRECTOR'S NOTES） | **中文【标签】+ 等号语法** |
| 风格锁 | STOP-MOTION 三重锁 + ANTI-DISNEY | **【风格＝绝对最高优先】+ 反光滑铁律** |
| 导演注 | DIRECTOR'S NOTES（英文） | **【导演笔记】×1,413（中文）** |
| 提示词长度 | 中位 10,114 | 中位 9,207（最长 37,751） |

**方法论启示**：**同一团队对不同批次/阶段用不同语言**——节选版（对外展示的精修版）用英文，完整版（大规模生产）用中文。中文的等号标签语法（【X＝Y】）比英文段落头更紧凑、更结构化，适合量产；英文段落头更适合对外交付。这为"何时用什么语言"提供了官方实证。

## 五、十二体系终极定位（KOK BÖRÜ 完整版收束）

至此全工作区十二个项目（官方 10 + 节选版与完整版互证 + 社区 DETOUR）全部完成。KOK BÖRÜ 完整版的独特贡献：
1. **风格范本的一元化统治**：全片 1,555 次【风格＝绝对最高优先】——比任何英文 GLOBAL LOCK 都高频
2. **中文量产语法**：【标签＝规则】等号语法是给中文团队的最优结构
3. **暗部条款与活体清单**：两个此前没有的新锁

## 六、复用检查清单（完整版增补——中文量产专用）

- [ ] 风格范本是否"唯一权威"且区分"怎么画"与"画什么"？
- [ ] 暗部是否被单独点名（夜色与暗部同样由笔触画成，绝不光滑渐变）？
- [ ] 表面反光滑铁律写了吗（光滑＝废帧；平滑只属于流体轨迹）？
- [ ] 段落第一法则（节奏判词）标注了吗？
- [ ] 动作的文化修辞锚定了吗（像猎人取工具，不像英雄拔圣剑）？
- [ ] 【活体清单】人数锁（动物大场面）写了吗？
- [ ] 中文量产用【标签＝规则】等号语法了吗？

How the API works (the short version)
Base URL: https://api.higgsfield.ai, docs at docs.higgsfield.ai
Header: Authorization: Key ID:SECRET
One POST per model slug (for example POST /seedance-2.5 with the mode and the parameters), the answer gives you a request id and a status_url
Poll the status_url until it is completed, then download the result
Before generating, POST /estimate/<slug> with the same body: it returns credits and USD. That is the "How much does it cost?" button of my tool
Reference images and videos go through files/generate-upload-url, then a PUT of the bytes, then you pass the file URL in the request
There is no balance endpoint and no library endpoint (I probed 20 routes, all 405). Keep your own history on your side, like my tool does

What broke and how I fixed it
Seedance 2.5 is token metered: the estimate endpoint returns a pricing description instead of a fixed USD number. The tool falls back to the public price table (dollars per second times duration) so the button never shows a blank
Optional integer fields (like the number of frames on Wan 3.0) were not being sent, and the estimate failed. Now the tool always sends the catalog defaults, required or not
The catalog JSON is big (3 pages, 77 modes). I store it once on the server and read it from there, instead of hitting the catalog on every page load
The secret is stored per user and masked in the interface. In the video the key never appears on screen

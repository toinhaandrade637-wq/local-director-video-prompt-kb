Create a Professional AI Character Reference Sheet




 Character Reference Sheet Prompt

Create an ultra-realistic, high-quality AI Character Reference Sheet using the uploaded reference image as the exact identity reference.

Character Consistency:

Preserve the same person's identity, facial structure, skin tone, hairstyle, eye color, and distinctive facial features.
Maintain consistent body proportions, height, age, and overall appearance in every view.
Keep the character's face natural and photorealistic, with realistic skin texture and lighting.
Do not change the person's identity between angles.

Character Sheet Layout:

Create a clean, professional character design sheet with the following views arranged in a well-organized grid:

Front View: Full-body standing pose facing the camera.
Side View: Full-body profile view.
Back View: Full-body view from behind.
Three-Quarter View: Body turned approximately 45 degrees.
Face Close-Up: Detailed facial portrait.
Facial Expressions: Neutral, happy, angry, surprised, and serious.
Pose References: Standing naturally, walking, and sitting.
Outfit Details: Clear views of the clothing, shoes, accessories, and fabric textures.

Clothing and Appearance:
Use the outfit shown in the reference image. Keep the same colors, clothing design, accessories, and hairstyle across all views unless a different outfit is specifically requested.

Visual Style:
Photorealistic, cinematic quality, natural skin texture, realistic anatomy, soft studio lighting, sharp focus, neutral grey or white background, professional character turnaround sheet, consistent proportions, clean spacing, high detail, 4K quality.

Composition:
Use a landscape 16:9 canvas. Arrange all views neatly in a professional reference-sheet layout. Keep the entire body visible in the full-body views. Ensure each angle clearly shows the same character.

Important Restrictions:
No duplicate body parts, no extra fingers, no distorted faces, no inconsistent clothing, no random accessories, no different identities, no cartoon appearance, no unnecessary text, no watermarks, and no cropped feet or heads.

Goal: Generate a master character reference sheet that can be used as a visual reference for consistent characters in AI-generated images, cinematic videos, advertisements, and storytelling projects.

Welcome to the Backrooms. Here's how I built it.

there are three steps: reference plate → still → swap.
everything done on higgsfield.ai, prompts are below, just copy & paste


1 BUILD YOUR REFERENCE ★

go to → Image on higgsfield.ai
choose Nano Banana Pro
upload a clean frame from your own footage, no person in it
upload 1–2 Backrooms Level 0 reference images alongside it
paste a still prompt from below
generate ★

photo tips: pull your plate from the actual clip you're going to animate, empty of people. match reference images to your camera angle as closely as you can.



2 GENERATE THE STILL ★

open Nano Banana Pro → select your source frame + references
paste the still prompt
generate ★


3 SWAP THE LOCATION ★

open Genjutsu
select Object Swap, not Motion Transfer
upload your source clip as the video input
select only the location/background to change, never the character
attach your approved still as the reference image
paste the matching swap prompt from below
generate ★

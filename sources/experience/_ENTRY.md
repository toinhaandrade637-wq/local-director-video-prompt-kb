## 2. 怎么找

### 按项目名

```bash
# 全流程方法论：直接看文件名
03-全流程方法论/DETOUR全流程创作方法论.md
03-全流程方法论/ONEIRIC全流程创作方法论.md
```

### 按主题

文件名带主题词，先列目录再挑：

```bash
ls 05-官方教程 | grep -i "seedance"
ls 05-官方教程 | grep -i "广告"
ls 05-创作者博客 | grep -i "character"
```

### 按 brief

```bash
05-官方项目brief/INDEX.md        # 总索引
05-官方项目brief/<项目>_brief全文.txt
```

## 3. 三类内容怎么用

| 类型 | 适合 | 不适合 |
|---|---|---|
| 全流程方法论 | 看一个项目从策划、资产、分镜到交付的完整拆解 | 找逐条提示词（去 `sources/higgsfield`） |
| 官方教程 | 学平台官方口径、参数、工作流 | 当创作风格参考 |
| 创作者博客 | 学真实工作流、踩坑、变现 | 当官方能力说明 |
| 官方技能包 | 直接加载或抄结构 | 当完整提示词库 |

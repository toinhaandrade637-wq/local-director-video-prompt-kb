Ten MCP servers let an AI agent generate video from Claude, ChatGPT, Cursor or a coding agent: Higgsfield, Runway, HeyGen, fal.ai, Dora, Vivideo, AITuber, OpenArt, Imagine.art and the open-source mcp-video-gen. They differ in which clients they document, whether an API key is required, and whose balance the generation hits. All facts below were checked on each vendor's own pages in October 2026.

How We Compared the Servers

The list includes servers that publish their own MCP documentation for at least one of Claude, ChatGPT or Cursor, plus one open-source option for self-hosting. Every server was then checked on the same criteria, taken from the vendor's own MCP page or developer docs. Facts verified October 17, 2026.

Where a vendor page does not state something, the card says so. Higgsfield takes the first slot because one connector covers a multi-model catalog together with characters, audio and ad workflows, all on one account and one plan-credit balance, with no separate API key to manage.

1. Higgsfield MCP: One Endpoint for Claude, ChatGPT and Cursor Without an API Key

Higgsfield MCP turns the models, characters and ad workflows of a Higgsfield account into tools an agent can call, billed to the credits that account already has. One endpoint, https://mcp.higgsfield.ai/mcp, works as a custom connector in Claude, an official plugin in ChatGPT and a marketplace add-on in Cursor. Coding agents go a different route: Claude Code, Codex, OpenClaw and Hermes install Higgsfield CLI with its companion skills and call it from there. You sign in with your Higgsfield account, so there is no key to create or rotate.

2. Runway MCP: A Plan-Based Connector With Plugins for ChatGPT and Cursor

Runway MCP connects Claude.ai, Claude Desktop, ChatGPT, Grok Bot, Cursor and Replit to a Runway account at https://mcp.runwayml.com/mcp. In ChatGPT, Grok Bot and Cursor it installs as a plugin. Elsewhere you paste the URL and sign in. No API key is needed.

4. fal.ai MCP: Raw Model Access With Explicit Queues

fal documents two routes to its model-generation server. The per-client guides for Claude, Claude Code, Codex CLI and Cursor use the OAuth relay at https://mcp.fal.ai/mcp-relay: you sign in in the browser and paste no key, and ChatGPT gets the same server as a plugin. The MCP overview page still show the standard endpoint https://mcp.fal.ai/mcp with a FAL_KEY in the client config for Claude Code, Claude Desktop, Cursor and Windsurf. A separate genmedia CLI uses a local API key as well.

5. Dora: Sixteen Models With the Cost Shown Before Generating

Dora is a hosted server at https://doravideo.com/mcp for ChatGPT, Claude, Cursor and Google Antigravity. Authentication is OAuth 2.1 or a static API key. The server exposes four tools on purpose: list_models, generate_video, generate_image and check_job.

6. Vivideo MCP: A Hosted Server or an Open-Source Package, With Avatars and an Auto Pipeline

Vivideo’s developer docs lead with the hosted server: point Claude Desktop, Claude Code, Cursor or any MCP client at https://api.vivideo.ai/mcp with your API key in the Authorization header, and there is nothing to install. The same 13 tools also ship as an npm package, npx -y @vivideo/mcp, for anyone who wants to run the server locally with the key in the env block. The package is open source under MIT.

# 专业剧本格式

WorkRally 的剧本**不是**独立写作 App。磁盘只有一份 Fountain 纯文本（`.fountain`），预览用 TipTap 把每一行定成元素。Agent 改文件请用 `read_file` / `edit_file` / `write_file`，不要发明剧本私有工具，也不要写 JSON Schema。

细则与反例见 [references/preview.md](./references/preview.md)。联调提示见 [references/test-prompts.md](./references/test-prompts.md)。动笔前先确认：要改的是磁盘源文件，不是预览 JSON。

## 适用

- 用户要「新建一个剧本」「新建剧本」「建一份专业剧本」
- 点名专业剧本格式或 `.fountain`
- 正在改已有 `.fountain`（改角色名、调场次、修预览定类）
- 预览里场次、角色、台词、os/vo、字幕对不上
- 需要按中文或好莱坞**观感**描述，但仍写入同一套 Fountain

## 不要做

- 不要在分析完整剧本、剧本改写、拉片还原、从剧本出分镜或视频时调用本技能
- 未指定专业剧本格式或 `.fountain` 时，不要把「写剧本」「改剧本」当成要建 Fountain（现有产出多为 `.md` / `.txt` / 应用内稿）
- 不要把剧本写成 Markdown 标题、列表、代码块
- 不要给中文角色名改成全大写英文行来「符合 Fountain」
- 不要把 `os`/`vo` 写成 `(V.O.)` 存进磁盘（预览好莱坞才会把两者画成 `(V.O.)`）
- 不要在源文件里写 `△` 或 `【字幕：】` 的装饰以外的格式；`△` 只在中文 PDF/Word 导出时加
- 不要把 `(O.S.)` 批量改成 `(V.O.)`：旧稿原样保留
- 不要写 sceneId / characterId / 角色字典 JSON
- 不要在正文写 `人物：张三、李四` 或手编场号：本场人物和场号都是预览从文档序推导的
- 不要给空角色框硬填人名（先写后补是合法的）；有台词/括注却没人名才要补

## 执行步骤

1. 确认目标是工作区里的 `.fountain`（`.md` / `.txt` 不会走剧本预览）
2. 按下方磁盘写法写入或修补
3. 需要核对预览时，对照 [preview.md](./references/preview.md) 的定类表，而不是按好莱坞纸质剧本的「看起来像」来猜

## 磁盘怎么写（预览才能认）

| 元素     | 磁盘写法                                                                                                                                                                                                                                                           | 预览                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| 场景标题 | `内景. 地点 - 日` / `车内. 客厅 - 午后` / `列斯.好剧啊. 出租屋客厅-1 - 花` / `1-1 日 内 酒店-大堂` / `INT. ROOM - DAY`；子地点用连字符 `酒店-大堂`；不像标题时用强制点 `.特写. 眼睛`。形状是 `前缀. 地点 - 时段` 即场次头，前缀不必含「内/外」，不要改写成 `内景.` | 场次控件（时间/内外景/地点/闪回）。磁盘仍是这一行。场号只读，按文档序 1、2、3，闪回 1A |
| 动作     | 普通段落。会被误判成场次/角色时用 `!` 钉住                                                                                                                                                                                                                         | 叙述。中文预览**不**显示 △                                                             |
| 台词     | 中文 `@张三` 或 `张三：台词`；英文全大写且下一行是台词。角色名可空（先写台词）                                                                                                                                                                                     | 一块：角色框 + 正文。中文一行 `人名：台词`                                             |
| 声音     | 中文黏连 `@张三os` / `@张三vo`；拉丁名 `JOHN (os)` / `JOHN (vo)`                                                                                                                                                                                                   | 中文预览 `张三os：`；好莱坞预览 `NAME (V.O.)`（os 与 vo 看起来一样，磁盘仍区分）       |
| 括注     | 角色后的 `(低声)` / `（低声）`                                                                                                                                                                                                                                     | 短剧口径开启才显示情绪框；关了仍留在文件里                                             |
| 字幕     | `【字幕：三年后】`                                                                                                                                                                                                                                                 | 字幕块；编辑器里不显示书名号                                                           |
| 转场字面 | `CUT TO:` / `>淡出。` / `【转场】…`                                                                                                                                                                                                                                | 按动作保留，不设独立转场元素。`>THE END<` 是居中动作                                   |
| 闪回     | 写在场次标题字面上，如 `内景. 客厅 - 夜 （闪回）` 或 `FLASHBACK`                                                                                                                                                                                                   | 场次控件上的闪回开关，没有独立 ID                                                      |

空文件载入是动作块。用户新建 `.fountain` 时客户端会写入一场 `内景. 地点 - 日`。文件开头可用 Fountain title page（`Title:` / `Episode:` / `Logline:` / `Notes:`，也可保留 `Author:` 等其它键）对应预览信息区；没有这些键就不要编 JSON 信息区。

## 改名、挪场、待补（仍改纯文本）

用户在预览里拖场次 / 点「全篇同步」是编辑器操作。Agent 没有对应工具，按下面改磁盘。

- **改角色名**：未说明范围时，同步所有 `@旧名` / `旧名：` / `旧名os` 提示行。用户说「只改这一句」才动那一块。不要改成 JSON id
- **改地点**：父级（`酒店`）全篇同步时保留子地点（`酒店-大堂` 仍是大堂）；子地点按「父-子」一对替换。内外景写在场次头上（`内景.` / `外景.` / 已有自定义前缀如 `车内.`）；同一地点别处已有众数内外景时跟众数，不要无故写成 `未识别`，也不要把 `列斯.好剧啊.` 改成 `内景.`
- **挪场**：剪切「场次头 + 直到下一场之前」整段，粘到目标位置。场号不要手改，预览按新顺序重编
- **待补**：侧栏只警告这些——有台词/括注却没角色名；场次地点空；时间或内外景是 `未识别`。空角色框、空动作不报，不要主动填

细节见 [preview.md](./references/preview.md) 的「派生信息」和「导出」。

## 写入后自检

- 中文名单独一行、没有 `@`、后面也不是 `：台词` → 预览会当成**动作**
- `张三os` 被写成 `张三 (V.O.)` → 磁盘丢失 os/vo 区分，且旧稿 `(O.S.)` 不该被改掉
- 字幕写成 `字幕：三年后` 而没有 `【字幕：…】` → 可能被拆成角色行
- Markdown `# 第一场` → 动作，不是场次
- 写了 `人物：张三、李四` → 变成动作，预览人物条不会认；人物条只看本场台词块
- 场次头写了 `1.` / `1-1` 当编号 → 打开后按文档序重编，不要靠它当稳定 ID
- `列斯.好剧啊. 出租屋客厅-1 - 花` 这种自定义前缀被改成 `内景. …` → 作者写的内外景字面丢了

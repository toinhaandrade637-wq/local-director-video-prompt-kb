# WorkRally Fountain 预览定类

本文说明 **本客户端** 如何把 `.fountain` 变成预览，以及中文 / 好莱坞两种画法。不是通用 Fountain.js 行为（它按 `[A-Z]` 认角色，中文几乎全会变成动作）。

## 管道

```
磁盘 .fountain
  → fountainToDoc（按行定类）
  → TipTap 元素（场次 / 动作 / 台词 / 字幕 / 插入）
  → 预览 CSS（writingPrefs.screenplayFormat，默认 chinese）
  → 保存时 docToFountain 写回纯文本
```

TipTap JSON **不是**产品存储格式。Agent 只改磁盘文本。

中 / 好切换、短剧口径只改预览和导出，不改元素类型。

## 行怎么被认

文件最前面若是 Fountain 键值（`Title:` / `Episode:` / `Logline:` / `Notes:` 等，直到空行）进信息区，不参与下面的行定类。`张三：` 不是 title page。

自上而下，空白行会打断「下一行还是台词」的状态。

1. **字幕** `【字幕：…】` / `【字幕:…】` → `subtitle`。不要写成 `字幕：` 否则可能被拆成「角色 + 台词」。
2. **转场字面** `CUT TO:` / `FADE IN:` / `FADE OUT.` / `>淡出。` / `【转场】` / `切至` → `action`，保留字面但不设独立转场元素；`>THE END<` 是居中动作并保留居中标记。
3. **场景标题**（一块：时间 / 内外景 / 地点父→子 / 闪回是 attrs，正文留空；场号按文档序只读）
   - 中文：`内景.` / `外景.` / `内外.` 开头
   - 自定义 `前缀. 地点 - 时段`：`车内. 客厅 - 日`、`列斯.好剧啊. 出租屋客厅-1 - 花`。前缀不必含「内/外」，原样写回，不要改成 `内景.`。同形动作句（`走吧. 他停了一下 - 然后`）也会被收成场次头，要用 `!` 钉住
   - 场号：`1-1 日 内 酒店-大堂`、`017 夜 外 巷口`（打开后写出规范字面 `内景. 酒店-大堂 - 日`）
   - 地点+日夜+内外：`江边广场 日 外`
   - 英文：`INT.` / `EXT.` / `INT./EXT.` / `I/E`；编辑后仍按英文场次标题写回
   - 强制点：`.特写. 眼睛`（没有点的「特写. 手」是动作；强制点原文进 `raw`，不要编成 `未识别. …`）
   - 拆不出时间/内外景时 attrs 为「未识别」，不默认填「日 / 内」
   - 时间 / 内外景和地点一样可输入：默认日/内，自定义值本篇其它场次可补全复用。Enter 从左到右确认（日 → 内 → 地点 → 子地点）；新建场次光标在时间框
   - 地点父→子用连字符：`酒店-大堂`（保存仍是这一行，不是两行）
4. **台词**（一块：角色名 / os·vo / 情绪是 attrs，正文是 content）
   - `@张三` 无论下一行是什么
   - `张三：你好。` / `张三os：别过来。`（短中文名 + 冒号）
   - 全大写拉丁名且**下一行有台词**：`JOHN` + `Hello.`
   - `HE WALKS IN.` 这种带句号的是动作
   - 角色名可空：先写台词时磁盘是 `@` 再跟正文
5. **括注** 只跟在台词期待态后面的 `(…)` / `（…）`，收进同一块的 `tone`
6. **其余** 动作。行首 `△` / `▲` / Fountain `!` 会被剥掉，只留下动作正文。

正文里的粗斜下划线用 Fountain `**粗**` `*斜*` `_下划线_` `~~删除线~~`。磁盘往返保留下划线，不要当成「导出会丢掉」。

## 派生信息（预览有、磁盘没有）

这些是 TipTap 从正文推出来的，Agent 不要写成独立段落或 JSON。

| 预览            | 怎么来的                                               | Agent 该怎么写                                          |
| --------------- | ------------------------------------------------------ | ------------------------------------------------------- |
| 场号 1 / 2 / 1A | 文档里场次头的顺序；闪回挂在上一场正场后面成 1A        | 挪场就移动「场次头到下一场之前」整段，不要手改编号      |
| 本场人物条      | 本场台词块里出现过的角色名，出场顺序去重               | 不要写 `人物：…` 动作行                                 |
| 侧栏待补        | 有台词或括注却没角色名；地点空；时间/内外景为 `未识别` | 空角色框不报。补的时候改对应场次头或 `@人名`            |
| 改名确认        | 预览里改已用过的名字会问全篇同步 / 只改本处            | 按用户范围改 `@旧名` / `旧名：`；地点父级同步保留子地点 |

同一地点再写一场时，内外景跟该「父+子」的众数，没有再跟父级众数，都没有则保留当前行已写的 `内景.` / `外景.`。

## os / vo（必须按这个写）

语义（短剧口径）：

- `os`：声音不是人物开口（内心独白、画面外）
- `vo`：叙述性旁白

磁盘：

| 写法                     | 解析结果                            | 再保存                     |
| ------------------------ | ----------------------------------- | -------------------------- |
| `@张三os` 或 `张三os：…` | 人名 `张三`，`extension=os`         | `@张三os`                  |
| `@李四vo`                | 人名 `李四`，`extension=vo`         | `@李四vo`                  |
| `JOHN (os)`              | 人名 `JOHN`，`extension=os`         | `JOHN (os)`                |
| `@JOHN (V.O.)`           | 人名带 `(V.O.)`，**没有** extension | 原样                       |
| `@李四 (O.S.)`           | 人名带 `(O.S.)`，没有 extension     | 原样（旧稿，不要批量改掉） |

不要把 os/vo 都写成 `(V.O.)` 存盘。好莱坞**预览**会把 `extension=os|vo` 都画成 ` (V.O.)`，这是呈现，不是文件内容。

英文名不要黏 `os`：`CARLOS` 不会被拆成 `CARL` + os。

## 两种预览

`writingPrefs.screenplayFormat`，默认 `chinese`。已写入 localStorage 的旧值不迁移。

**中文**

- 场次：衬线、顶部分隔，不是灰底 slugline。控件排成 `1 日 内 酒店-大堂`，时间/内外景/地点都是可输入补全，不是手打一行
- 动作：编辑器里**没有** △；导出 PDF/Word 才加
- 楷体栈 + 动作首行缩进 2 字；场次头顶格，转场字面和其它动作相同
- 台词一块：角色名在 attrs，正文才是 content；中文排成一行 `张三os：别过来。`（冒号是块上的铬）
- 角色名可空（先写台词）；`os`/`vo`/`：` 是呈现，不写进正文
- 场次头下有只读人物条（本场台词名）；侧栏可拖场次组重排

**好莱坞**

- Courier 等宽；场次 / 角色名 `text-transform: uppercase`（只影响拉丁字母，磁盘不变）
- 台词块：提示居中，正文左右缩进；转场字面和其它动作相同
- `extension` 在角色名后显示 `(V.O.)`

## 短剧口径

`shortDramaMode` 默认关。关：编辑器和导出藏起情绪框，文件里的 `(低声)` 还在。开：人名旁边露出情绪。

## Enter / 插入

| 当前块 | Enter 后                 |
| ------ | ------------------------ |
| 场次   | 动作                     |
| 动作   | 动作                     |
| 台词   | 新的空台词块（空角色框） |
| 字幕   | 动作                     |
| 插入   | 动作                     |

字幕和插入块**不要**靠连续回车去「造出来」，用插入菜单或工具栏。Tab / Shift+Tab 切换**整块**类型（场次 → 动作 → 台词 → 插入，跳过字幕），角色名和场次头控件里也一样，不要用 Tab 在日/内之间跳。场次头四栏横向排：光标在端点时左右键换栏，下拉里上下键选日夜。Enter 才确认并走到下一栏（日 → 内 → 地点 → 子地点），角色名 Enter 走进台词。空角色名聚焦也列出全员。本场末尾 `Cmd+Enter` / `Ctrl+Enter` 插入空场次头（继承上一场时间，地点留空），光标落在时间框。空场次头 Enter 在下方插入动作，不把当前场次改成动作。地点为空时，地点框里 Backspace / Delete 删掉这一场（只剩一场则重建空场次头，不改成动作）。文档第一块场次头不能被改成台词/动作。

## 导出

- Fountain：就是磁盘原文（含下划线），不是转换
- Word：读当前中/好和短剧口径。中文左齐、动作前缀 △、os/vo 接在人名后；场次下写 `人物：A、B`，闪回场前后 `【闪回】` / `【闪出】`
- 好莱坞 Word **不写**人物列表行；短剧口径开着时，连续同角色台词只留**首个**括注，后面的括注丢掉
- 有台词/括注却没角色名：Word 仍导出，角色名位留空
- PDF：截预览 DOM；中文打印样式会补 △ 和字幕书名号
- 导出 Word 后的「这次丢了什么」只记在内存（人物列表、连续括注、空角色名），不是磁盘审计日志，也不要写成文件里的 JSON

## 反例（预览会认错）

```text
# 第一场                    ← Markdown，当成动作
张三                        ← 单独中文名，当成动作（要 @张三 或 张三：台词）
张三 (V.O.)：别过来。        ← 存成 (V.O.) 就分不清 os/vo
字幕：三年后                ← 缺【】，可能被当成角色「字幕」
>THE END<                  ← 居中动作，不是转场
△他走进来。                ← 能解析，但保存时 △ 会被剥掉；不要依赖它当格式
人物：张三、李四            ← 变成动作；人物条只从本场台词推导
```

推荐：

```text
内景. 客厅 - 夜

他走进来。

@张三os
别过来。

【字幕：三年后】

CUT TO:
```

## 二、单项目标准作业程序（SOP，六步 · 2026-11-04 升级：最严最全维十维清单）

**十维全覆盖（每维都要有产出，缺一不算完成）**：
1. 机读分拣（model/type/唯一率/迭代率/长度分布）
2. 块头分类学（全语料块头频次表）
3. 代表全文精读（每模板族最长代表，散文体逐节读）
4. NEGATIVE 栈分类学（四族归纳+Top 频次）
5. 资产卡/引用系统清单（名义资产、UUID 标签、光态变体）
6. 风格 DNA 词频（实词 Top35）
7. schema 维度（aspect/duration/size 分布，JSONL 缺则标注 API 可取）
8. skill 与 brief 核查（skill 有无、brief 全文/存根）
9. 团队语法归属（studio 散文体/结构体、commercials、soul）
10. 双轨 K 页生长（生图→生图轨，视频→视频轨，带 [案例] 标注）

1. **全量载入**：读 02区 `<项目>/xxx_all_prompts.jsonl` 全部行（不抽样）。
2. **机读分拣**：按 model/type 切分生图 vs 视频 vs 上传；统计模型分布、唯一率、迭代率。
3. **深读提炼**（生图+视频双线）：
   - 生图线：角色表/风格块/参考用法/光线模板/材质词汇/负面约束——逐类抓 verbatim 例句
   - 视频线：运镜指令/连续性机制/表演任务/声音衔接/转场语法——同上
   - 风格 DNA：高频词证据（word-frequency）+ 视觉签名
4. **落笔记**：`06_知识库/研究记录/P<项目>_全量分析.md`（verbatim 例句 + 模板 + 常见错误 + 风格 DNA 章）。
5. **知识页生长**：新方法 → 增补对应 K 页（标注 [案例] 项目名+条数）；生图方法 → 生图/01 生图提示词方法页（主粮：cineimage-soul + 项目实证）；更新 索引.md + index.json。
6. **记账**：维护/全量收割计划.md 勾掉该项目 + 事件记录追加。

完成判据：该项目的提示词 100% 经过机读分拣，生图与视频两线各至少产出 1 条可复用方法或验证 1 条既有方法，笔记落盘，K 页更新。

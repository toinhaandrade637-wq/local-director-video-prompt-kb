## 新块型发现

1. **OUTPUT CONTRACT×865**（one-the-mercy-ledger）：输出合同独立块——指定输出格式的合同式约束
2. **SETUP AND BLOCKING + ACTION + TONE,STYLE AND MISE-EN-SCENE 三联分节**（my-way-navillus-teaser）：三节并行结构（走位+动作+调性）
3. **FACE & BODY PERFORMANCE×952**（madseason）：面部与身体表演独立块（比 FACE AND BODY PHYSICS 更细粒度）
4. **CAMERA×1791**（madseason）：相机块全库第二高单块计数（仅次于 one-day-with-mr-otter LIGHTING×1350 之后）
5. **HERU — OUTSIDE THE FEED×103**（heru-out-of-his-time）：角色名+场景描述合并块（角色即场景标签）
6. **GEOMETRY MAP×29 + FIRST FRAME×29**（ctrl-hold-mv）：几何地图+首帧成对出现（45 行微型 MV 中每条都有）
7. **NO ON-SCREEN TEXT — CRITICAL×29**（ctrl-hold-mv）：否定+CRITICAL 合并（更严格的禁令标记）

## 结论 → K 页生长

1. **OUTPUT CONTRACT** → 通用轨重建时纳入（输出格式合同式约束）
2. **SETUP AND BLOCKING / ACTION / TONE 三联分节** → 视频轨重建时纳入（结构化模板的另一形态）
3. **FACE & BODY PERFORMANCE** → 视频轨表演维度（比 PHYSICS 更专注于表演面）
4. **GEOMETRY MAP + FIRST FRAME 成对** → 视频轨空间锁定（与 ANERNEQ LOCATION MAP 同族）
5. **madseason CAMERA×1791 + one-day-with-mr-otter LIGHTING×1350** → 手写项目的超密度块实例

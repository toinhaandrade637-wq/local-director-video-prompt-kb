## 铁律

- **资料库不可改写**：`02_完整提示词数据包`、`学习的影片全部提示词`、`05_经验类内容` 原件一根手指都不动；知识页只引用（带项目名+来源）
- **来源编号制**：每条进入 K 页的新方法必须先在 [维护/来源登记.md](维护/来源登记.md) 登记 Sxx 编号；无编号的方法不得进页
- **现行知识是唯一维护正文**：结论只写在方法页里；正文不引用深读笔记，一律给结论 + 来源标注
- **方法页头部必须有**：状态（trial/validated）、证据分层、更新日期、依据（来源清单）、页尾待验证生长点
- **事件只追加**：`维护/事件记录.md` 记录每次变更，不改旧事件
- **结论分层标记**：[官方] 官方原文 / [案例] 项目实证 / [实测] 统计 / [用户经验]，不得混写
- **数字必须有出处**：来自实测脚本或官方面板，禁止拍脑袋
- **引文保真**：verbatim 例句必须与解析后源文逐字一致（含换行），写入含反引号内容走 Write 工具不走 bash
- **`03_全流程方法论` 是历史档案**：按项目组织的静态文档，不再更新；新知识只进本库
- **原文优先（2026-11-04 铁令）**：知识生长必须读**原文**——02区 JSONL 提示词全文、05区 教程/博客/技能 SKILL.md 原文；**禁止以研究记录/深读笔记等既有总结为知识依据**（总结只作索引用，且按"乱总结"嫌疑对待——引用前必须回原文核验）
- **收录源逐字全读（2026-11-04 铁令 · E189）**：每次读取，凡涉及一个项目/来源，必须把与它有关的**全部收录源材料逐字看完，不出错**——02区 JSONL 提示词每条逐字 + brief/介绍页全文 + 05区 SKILL.md/官方博客/教程/创作者博客全文 + 其他一切已收录材料（README.json/元数据/索引简介等）。抽样、跳读、只跑脚本看统计、只看总结**都不算读完**；逐字读完之前不得产出该来源的知识结论。已开读的来源必须读满 100% 才算完成，暂停过的（如 ANERNEQ 逐字 #120/#140）一律回填补满。全文见 [知识库建设蓝图.md](知识库建设蓝图.md) 铁令追加节

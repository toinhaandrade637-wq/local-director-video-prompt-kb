# 视频/05 多主体调度（视频轨）

多主体场景的核心难题：**两个角色共享一个锚点时特征会混合**。解法=每个角色独立参考 + 色板分离 + 计数锁 + 比例锁 + 位置锁。

## 一、五种混合失败模式 [官方 S15]

| 失败 | 表现 |
|---|---|
| **Blending** | 两个角色漂移向一张平均脸 |
| **Swapping** | 发型/服装/道具在镜头间从一个角色移到另一个 |
| **Duplication** | 多视图参考表被字面复制，同一角色出现两次 |
| **Scale drift** | 儿童和青少年变成同高，或镜头间互换身高 |
| **Shot-to-shot drift** | 第一镜正确，第三镜角色略有不同 |

## 二、四条路线选择 [官方 S15]

| 路线 | 适用 | 工具 |
|---|---|---|
| Motion transfer | 已有两人物表演视频 | Genjutsu |
| Objects swap | 片子好但需替换一人 | Genjutsu |
| **Cinema Studio 4.0 分参考** | 自建两人场景 | Soul 2.0 + CS 4.0 |
| Soul ID + Elements | 角色需跨项目回归 | Soul + Elements + CS 4.0/Seedance |

## 三、三板角色表语法 [官方 S15 verbatim]

每个角色一张 Soul 2.0 生成的 16:9 三板参考表：

```text
LEFT PANEL: full-body rear view, head and shoes in frame
CENTER PANEL: large frontal face close-up, full hair silhouette
RIGHT PANEL: full-body front view, head and shoes in frame
```

**关键语法要素**：
- 服装在每个 panel **逐字相同**（"identical in every panel"）
- 干净背景 + 柔和均匀光
- 年龄标记独立（"clearly 15-year-old, not an adult actor playing a teenager"）
- 肤色特征精确（flat freckles not raised spots / warm peach undertone）
- 禁止 facial hair/stubble/beauty filter

**动物角色表**同格式，但改 quadrupedal stance（不用 upright human-like posing）+ animal eye level camera。

## 四、色板分离策略 [官方 S15]

两个角色故意相似（copper-red hair + freckles）但通过**不重叠色系**区分：
- Jerry（15y）：**mustard yellow + indigo denim**
- Lucy（8y）：**purple + cream**

> `wardrobe palettes that do not overlap`

这确保即使面部混合，服装颜色也能区分身份。

## 五、道具独立参考 [官方 S15]

重复出现的道具（remote control）**单独生成参考**，精确到厘米和色值：

> `approximately 16 centimeters long, 13 centimeters wide, 4.5 centimeters thick`
> `sRGB #D1FE17`

关键约束：
- 比例显式（fits across two cupped teenage hands）
- 按钮数量精确（EXACTLY ONE BUTTON）
- 色值锁定（sRGB #D1FE17）
- 禁止额外功能（No additional controls, screens, antennas）

## 常见错误

1. 两个角色共用一张参考图→blending
2. 只有文字描述没有人像参考→identity 不锚定
3. 色板重叠→服装无法区分身份
4. 忘了计数锁→模型多复制角色
5. 忘了比例锁→儿童和成人变同高
6. 场地图含人物→额外角色进入场景
7. 道具没有独立参考→道具在镜头间变形
8. 忘了 position lock→角色在镜头间换位

# Higgsfield 视频提示词

先读下方"按任务读方法"选页。所有方法均带来源编号（Sxx/项目#），短摘录为项目提示词逐字；引用时保持逐字。知识由 02区 原文逐字全读生长（铁令：原文优先），规则随项目收官持续重写。

## 共同骨架

**生成目标一句话 → 参考分工（谁管身份/造型/场地/构图）→ 镜头段（首帧状态/节拍/运镜/光声）→ 结束状态与约束。** 每个节拍独立可读；收尾三型（空帧/空地/未解决）。

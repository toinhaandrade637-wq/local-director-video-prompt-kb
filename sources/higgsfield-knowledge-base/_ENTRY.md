## 3. 页面怎么读

每页的结构：

```text
状态（trial / validated）
证据分层（[官方] / [案例] / [实测] / [用户经验]）
方法 → 适用情形 → 短摘录 → 好在哪 → 迁移法
页尾待验证生长点
```

引用格式：`HF:视频/03`、`HF:通用/02`。

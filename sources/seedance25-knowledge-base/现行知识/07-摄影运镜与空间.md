# 摄影运镜与空间

把摄影写成一条观察过程：**从哪里看谁或什么 → 随什么事件移动或调整 → 最后看清什么。**焦距、景别和操作名称放在这条过程里，帮助确定取景与观看感受。

## 分清机位、朝向、焦距和焦点

先交代摄影师的位置、高度与支撑方式，再写镜头怎样调整。站立肩扛向下摇，改变的是俯仰；变焦收紧改变取景范围；向人物靠近改变摄影位置；对焦决定何处清楚。从耳侧擦过或穿过人群，要写实际经过的路线。

人物路线与摄影路线分别说明。摄影机绕行时，角色继续原有动作；摄影机后退跟拍时，人物在画幅中的大小随双方速度差变化。复杂调度补起点、经过位置、观察中心和终点，简单固定观察可用一两句交代。

## 让纪录片手持感来自操作

**短摘录｜P039，奔跑敲鼓中的追拍**

> 摄影师努力保持男孩在画面内，脚步造成中等幅度、轻重不齐的上下颠动，偶尔因速度差让主体滑向画幅一侧，再通过小幅摇摄找回。画面不始终精确锁住面孔，注意力主要放在男孩的奔跑和敲鼓动作上，鼓面与双手尽量保持可见。背景连续掠过，衣料、鼓带随动作摆动，结束时奔跑与敲鼓继续。

**好在哪：**脚步产生颠动，速度差造成构图偏移，小幅摇摄找回主体；“鼓面与双手”又限定了摄影师真正要保住的信息。背景、衣料和鼓带继续运动，把人、相机与环境串在一起。需要这种观看方式时，按“操作原因—画面变化—修正—关键可见物”展开，比只加“剧烈手持”更具体。

手持的幅度随呼吸、后退、停步、转身或避让变化。主体先动，摄影师稍后修正；过冲或短暂失焦后，找到的是已经继续推进的事件。平稳观察、固定机位或持续清晰，同样可以直接采用，按场景决定。

## 空间关系与局部取景

分别确认世界站位、身体朝向、头部视线和当前画幅位置。人物面朝对岸可以作为基准，转头看同伴是局部动作；机位换到正面或反打，人物仍站在原处。换镜后结合轴线和观察方向重新确定画面左右。

先确定该镜必须看清什么，再决定裁切和遮挡。P039的耳部特写通过此前跑近建立人物归属；P042闻嗅时只露蘑菇局部，抬手与持握把它接回前镜。脚部特写用落点、重心和步伐表达动作，面部近景再承担眼神信息。

焦点跟随观看重点。P054说到画中的关键间隙时，镜头留在证据上，人物声音继续来自画外。抽焦、寻找和遮挡能表现现场感，但最终应留出看清关键对象的机会。

写完沿摄影路径走一遍：位置能接上，人物方向可辨，重要接触与表演在所需时刻入画，镜尾留下下一段可承接的取景状态。

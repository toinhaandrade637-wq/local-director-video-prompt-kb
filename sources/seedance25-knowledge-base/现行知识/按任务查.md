# 按任务查

先确定这次交付是什么，再选择必要方法。已有剧情、参考职责和用户约定直接沿用；不要求每次读完全部知识页。需要从偏差排查时转到[按问题查](按问题查.md)，全部主题见[知识索引](索引.md)。

| 当前任务 | 建议阅读路线 | 应得到的结果 |
|---|---|---|
| 根据已有剧情或分镜编写提示词 | [用户约定](01-用户约定.md) → [通用结构](02-通用结构与选用.md) → [本场发展](04-全局设定与本场发展.md) | 明确生成目标，按观看顺序组织综合小段；按内容再补相关方法 |
| 完善现有提示词 | [连续性与去重复](11-连续性约束与去重复.md) → 具体问题对应页 | 保留既定故事和有效细节，解决冲突、缺失与无用复述 |
| 续镜、延长或删段后接续 | [入口差异](12-Seedance入口与平台差异.md) → [跨镜衔接](09-声音与跨镜衔接.md) → [连续性](11-连续性约束与去重复.md) | 分清画面匹配、状态接续和实际视频延长，接住当前进度 |
| 细化对白、方言或人物反应 | [表演对白与方言](05-表演对白与方言.md) → [声音与跨镜](09-声音与跨镜衔接.md) | 目的与触发进入表演节拍，台词、口型和听者状态连续 |
| 更换参考或从参考生成迁移到文生 | [参考分工](03-参考分工与主体一致性.md) → [入口差异](12-Seedance入口与平台差异.md) → [通用结构](02-通用结构与选用.md) | 明确保留与替换属性，补齐失去参考后出现的信息缺口 |
| 优化动作、打戏或特效 | [动作因果](06-动作因果与打戏.md) → [摄影与空间](07-摄影运镜与空间.md) → [材质与环境](08-光影色彩材质与环境.md) | 动作有应对和结果，关键关系可见，环境与材料承接受力 |
| 设计已有内容中的连续变化 | [连续转场](10-连续转场与阶段变化.md) → [摄影与空间](07-摄影运镜与空间.md) → [声音衔接](09-声音与跨镜衔接.md) | 两端状态、中间过程与保持项都清楚，阶段不被误写成切镜 |
| 分析实际生成失败 | [问题导航](按问题查.md) → [实践记录](../实践记录/任务索引.md) → [待验证问题](../维护/待验证问题.md) | 先描述可观察偏差与当次条件，再区分原因假设和下一次比较 |

新材料的阅读、归纳与修订按[工作流程](../维护/工作流程.md)进行。一次输入可以影响多页；补条件、纠正或合并旧方法，同样是知识积累，不要求每次新增页面。

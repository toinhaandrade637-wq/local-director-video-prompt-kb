# 按问题查

下面的路线帮助定位需要检查的关系，不把生成偏差自动归因于某一句提示词。先保留当次输入、参考职责、入口、提示词版本及可观察结果；只有文字检查时，也应明确尚未观看或生成媒体。

| 遇到的问题 | 优先查看 | 核对重点 |
|---|---|---|
| 内容很多，却不知道先看什么 | [本场发展](04-全局设定与本场发展.md)、[通用结构](02-通用结构与选用.md) | 生成目标、观看任务、信息先后与段落层级 |
| 人物变脸、道具换样或多出一个主体 | [参考分工](03-参考分工与主体一致性.md)、[连续性](11-连续性约束与去重复.md) | 编号归属、采用属性、主体数量和有效版本 |
| 强调一致后人物不动，或无故锁住首帧 | [用户约定](01-用户约定.md)、[约束范围](11-连续性约束与去重复.md) | 要保持的属性是否被扩大成姿态、动作或首帧 |
| 动作重做、接不上，物件凭空换位置 | [连续性](11-连续性约束与去重复.md)、[动作因果](06-动作因果与打戏.md) | 已完成进度、持有者、接触结果及删段后的入口 |
| 打戏只有特效、双方没有来回 | [动作因果](06-动作因果与打戏.md)、[摄影与空间](07-摄影运镜与空间.md) | 攻击目标、应对、位移、结果和关键接触是否可见 |
| 情绪贴脸、全程同样哭喊或僵硬轮流说话 | [表演对白与方言](05-表演对白与方言.md)、[声音衔接](09-声音与跨镜衔接.md) | 人物目的、触发词、保护方式变化、让话和未完状态 |
| 方言、音色或发音提示混在一起 | [表演对白与方言](05-表演对白与方言.md)、[声音衔接](09-声音与跨镜衔接.md) | 目标语言、同一次发声、参考声音归属及字幕选择 |
| 人物方向跳变、镜头运动含混或关键部位看不见 | [摄影与空间](07-摄影运镜与空间.md) | 世界位置与画幅位置，机位、朝向、焦距、焦点各自变化 |
| 光线逐镜漂移、材质塑料感或环境统一乱晃 | [光影材质与环境](08-光影色彩材质与环境.md) | 实际光源、受光面、材料接触与环境动态来源 |
| 转场跳过去、慢动作变定格或画风串段 | [连续转场](10-连续转场与阶段变化.md)、[约束范围](11-连续性约束与去重复.md) | 中间状态、保持项及主体、摄影机、媒介的独立变化 |
| 设定相互否定、禁令越写越长 | [连续性与去重复](11-连续性约束与去重复.md) | 先确定采用版本，再解矛盾；只删无新增作用的重复 |
| 首尾帧、比例或时长与预期不同 | [入口与平台差异](12-Seedance入口与平台差异.md) | 实际任务模式、素材角色和提交设置；旧快照是否仍适用 |

查到方法后，把本次观察和处理结果接回[实践记录](../实践记录/任务索引.md)。尚无证据的解释进入[待验证问题](../维护/待验证问题.md)，按[工作流程](../维护/工作流程.md)修订；文件或行为检查通过不能替代生成效果验证。

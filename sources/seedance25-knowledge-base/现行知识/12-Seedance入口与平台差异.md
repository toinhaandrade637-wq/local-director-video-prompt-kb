# Seedance入口与平台差异

先选这次要完成的任务，再分配素材职责，最后对齐所用入口的提交设置。这样，镜头和表演可以用同一套内容骨架表达，换成文生、图片参考或视频参考时，只调整真正依赖输入的部分。

## 任务与参考输入分开判断

| 当前任务 | 写作重点 |
|---|---|
| 新生成 | 生成内容、素材各自提供什么；参考视频也可只提供动作或运镜 |
| 编辑已有视频 | 唯一原片、改动对象与时段或区域、目标状态和保留项 |
| 向后延长 | 原尾部位置、动作进度、道具与光声，随后发展什么 |
| 向前延长 | 前置内容怎样到达原首部的指定状态 |
| 两段之间补过渡 | 两端状态、连接过程与需要继承的条件 |

图片、视频、音频、独立关键帧、宫格或白模可以为同一任务承担不同职责。例如新生成时，视频提供运镜，人物图提供身份，音频提供音色；延长时则先明确原片接点，再补后续变化。

## 短例：把“视频参考”具体拆成它负责的信息

P024 原文中的两处短摘录：

> @Video 1 defines ONLY the exact 30-second action and editing blueprint: shot order, cut timing, downhill route, rider trajectory, stunt timing, camera positions, tracking paths, lens changes, foreground wipes, speed changes and audio rhythm.

> @Image 1 is the canonical identity, fashion, unicycle, environment and color reference.

第一句具体列出视频负责的镜序、切点、路线、轨迹、摄影与节奏；第二句把人物、服装、车、环境和色彩交给图片。两份素材因而可以共同服务一支新片。借鉴时先写“这份素材负责什么”，再把最终主体真正怎样运动写进正文。若改成文生，就将图片承担的必要外观、环境与色彩，以及视频承担的路线与镜序，补成文字；已有详细正文继续沿用。

## 把创作意图落到入口设置

提示词写清首帧、尾帧、人物身份、场景等用途；提交时在界面或API里选择对应的素材角色、画幅和时长。做画面匹配时，对齐指定构图；做状态接续时，接住已有动作进度；延长原片时，按当前入口提供原片与延长方向。

首尾画面任务要把**素材角色和画幅设置一起核对**。现有官方来源中，O003描述文字指定首尾图后锁首帧比例；O004区分 `first_frame/last_frame` 与 `reference_image` 加文字指定，后者保持独立比例设置。遇到这类任务，以正在使用的产品模式和实际角色设置确定操作；其余提示词仍按既定画面目标编写。

独立关键帧可对齐指定画面；宫格故事板交代镜序或动作发展；白模可提供空间、动作或摄影。分别写明采用哪些信息，再补齐最终人物、材质和照明。

## 保持内容骨架，按入口完成提交

成稿继续使用概述、素材分工、局部综合段落和结束状态。精准参考已完整表达的信息可以简写，关键新增动作、目的和表演则在对应小段展开。换入口主要调整输入绑定和参数，已清楚的事件关系可以保留。

提交前按当前入口查看素材数量、单次时长、延长方式和格式选项，采用任务所需的量。时间码用于表达安排，台词、动作与留白共同决定每段需要的时间。

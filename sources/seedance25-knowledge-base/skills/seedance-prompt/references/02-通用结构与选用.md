# 通用结构与选用

共同骨架是：**生成目标 → 参考职责与全局条件 → 按观看顺序展开的综合小段 → 结束状态及必要约束。** 稳定的是信息关系，栏目和篇幅随内容伸缩。

## 从开头进入具体过程

开头用一两句交代主体、地点、主要事件和重要观看方式。参考素材承担什么，在这里说清；没有参考时，文字直接建立所需外观与空间。

全局写贯穿这组镜头的时间地点、风格、光源天气、空间基准与声音选择。本场发展回答：开场已经怎样，什么推动变化或保持，最后留下什么。简单内容可并入概述，复杂内容再独立成段。

正文先分清三个层级：叙事段落可以包含几个镜头；镜头是一次连续摄影；节拍是镜内动作、反应或注意的变化。切镜另起镜头，长镜头内部按过程分阶段。

每个小段接住当前主体与状态，然后沿事件展开：谁因什么行动，怎样回应，摄影机让人看清什么，当时的环境光声怎样参与，段尾停在什么进度。根据这一段的观看重点取舍信息。

## 短摘录：动作、摄影和光声留在同一小段

P041《男孩被架离圣地并关入黑屋》，男孩把背后的鼓移到身前并坐下后的镜尾：

> 摄影师停止走动，随着坐下缓慢下摇，保留肩扛余颤。主角男孩坐稳后低头抱鼓，鼻下痕迹仍在，不增加哭喊或敲鼓动作。以男孩蜷坐在黑暗中的状态结束。光影：小窗是关门后唯一可见的光线来源，只让脸、手或鼓的局部依实际位置微弱显露，其余留在暗处。现场声：鼓带摩擦、坐地时的轻响与呼吸，室外声音遥远。

**好在哪：**下摇跟着坐下，画面落到低头抱鼓；小窗决定哪些局部能被看见，坐地与鼓带声又跟着动作发生。摄影、表演和环境围绕同一件事组织，“光影”“现场声”虽有小标签，仍属于这个镜头的完整过程。换题材时照着这种关系写，就能保持局部段落的规整。

## 按复杂度选择正文外观

| 当前内容 | 合适的展开 |
|---|---|
| 简单观察或单一动作 | 少量全局加一个综合段 |
| 普通多镜 | 每镜一至数段，写清入口、发展和接续 |
| 长镜头或连续转换 | 同镜分阶段，并行说明主体、相机与环境变化 |
| 表演密集对白 | 先定镜头，再按目的和台词触发拆镜内节拍 |
| 光声条件较复杂 | 综合正文后补本镜光影、现场声 |
| 需要逐项核对的复杂阶段 | 在同一时段内分类写人物、相机、背景，维持事件联系 |

动作特写着重接触、支撑与材质；面部近景可以细写目光、呼吸和声音；远景先让方向、规模与关系可辨。P043参考充分，简式分镜已经能交代事件；P037的话语交接复杂，值得展开到镜内节拍。内容决定细写哪里。

写完沿观看顺序读一次，检查因果、可见性和相邻段的状态。时长要容纳顺次动作、发声与必要停留，同时辨认哪些动作能并行。结尾既可以完成，也可以停在继续行走、保持观看或未说完的话上。

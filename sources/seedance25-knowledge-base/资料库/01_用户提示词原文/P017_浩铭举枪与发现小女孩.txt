【o秒-2秒|第一个画面:浩铭被吓到举枪的特写】严格按你的要求，第一个画面就是浩铭被吓到举枪的特写。\
\
镜头先给浩铭脸部和上半身的近距离特写。\
\
浩铭背贴左侧墙面，原本已经在房间里暂时停住。\
\
突然听见屋内深处那一下轻微的瓷器声之后，他猛地转头，瞳孔收紧，眼神骤然变得锐利而警觉。\
\
右手里的手枪几乎是本能反应般迅速抬起，从胸前低位一下举到瞄准位置。\
\
动作要快，但不是耍帅拔枪，而是被吓到后的战场本能。\
\
他呼吸一下子收住，肩膀绷紧，嘴唇轻抿，眼底带着惊惧和杀机，枪口直指房间右前方黑暗深处。。。。。【2秒-4秒|过肩镜头:看见碗和手】镜头切到浩铭左后肩的过肩视角。\
\
画面保持空间正确:\
\
浩铭在左前景，举枪对准房间中央偏右的桌子方向。\
\
桌子在中景。\
\
桌子下面，图1那只旧碗静静停在地面上。\
\
桌子后方更深处的黑暗里，那只小小的手还停在那里，刚刚像是想去够碗，现在因为被枪口指着而僵住。\
\
整个房间非常安静。\
\
没有人说话。\
\
只有浩铭压住的呼吸声和屋外很远的枪声。\
\
【4秒-6秒|低机位:枪口对准桌下，手慢慢缩回】镜头放低，接近地面高度，从桌脚之间拍进去。前景能看到手枪枪口切进画面，带来强烈压迫感。\
\
碗就在桌下中央偏前位置。\
\
那只手在桌下黑暗里犹豫一下，开始本能地慢慢往回缩。\
\
动作非常小，非常怕。\
\
不要立刻露脸。\
\
只通过这只手就让观众知道，躲在桌下的是个活人，而且很害怕。。。【6秒-8秒|浩铭沿左侧慢慢蹲低靠近】\
\
镜头回到中近景。\
\
浩铭没有立刻开枪。\
\
他盯着桌下，脸上的紧张开始从“发现威胁”慢慢转成“怀疑不是妖怪”。\
\
他仍然举枪，但食指不要立刻扣死扳机，而是微微收住。\
\
浩铭贴着左侧墙，沿着墙慢慢蹲低一点点，身体重心压低，尽量不发出声音。\
\
他的左肩还靠着墙，右手举枪，整个人仍然在左边。\
\
这个动作必须很谨慎，很慢，像在确认桌下到底是什么。\
\
【8秒-10秒|第一次露出小女孩的脸】\
\
镜头再切低一点，从桌子另一侧或桌脚之间慢慢看进去。\
\
桌下深处的阴影里，终于露出一张小女孩的脸。\
\
她不是完整爬出来，而是缩在桌子最里面，半张脸从黑暗里慢慢显出来。\
\
脸上脏兮兮的，沾着灰，眼睛很大，惊恐地看着枪口，也看着浩铭。\
\
她的另一只手紧紧缩在身前。\
\
她不哭，不喊，只是被吓得不敢动。\
\
气氛一下从“可能有敌人”变成“原来是个藏起来的小女孩”【10秒-12秒|浩铭意识到是孩子，枪微微放低】\
\
镜头给浩铭近景。\
\
他看到小女孩之后，眼神明显变了。\
\
从刚才那种要开枪的紧绷，变成震了一下、愣了一下，然后警惕中带一点不忍。\
\
他没有完全放下枪，但枪口很明显地往下压了一点。\
\
呼吸重新出来一点。\
\
他嘴唇微动，极低声、近乎气音地说一句中文:\
\
“别出声....”\
\
声音非常低，克制、沙哑、急，但不是凶。\
\
这是他对小女孩说的第一句话。【12秒-13.5秒|小女孩把碗慢慢抱回去】\
\
小女孩听见后，没有说话。\
\
她先看着浩铭，再看地上的碗。\
\
她很小心、很慢地伸出手，把那只旧碗往自己怀里轻轻拉回去。\
\
动作非常珍惜，像这只碗对她非常重要。\
\
她把碗抱进怀里，缩得更紧。\
\
她眼睛还是一直看着浩铭，既害怕又不明白他是谁。。。。。。。

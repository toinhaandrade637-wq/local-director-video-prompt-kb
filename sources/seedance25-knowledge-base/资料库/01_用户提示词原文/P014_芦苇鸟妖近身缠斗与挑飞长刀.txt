镜头1｜超低机位大透视近景\
摄影机贴近泥水与芦苇根部。\
\
鸟妖单膝跪在芦苇间，单手以铜色细长刀撑住地面，长颈微垂，衣袍和羽毛被狂风掀动。它突然察觉左侧逼近的动静，猛然抬头。\
\
主角从画面左侧高速刺入，身体前压，银色宝剑直指右侧，形成强烈水平攻击线。鸟妖瞬间起身，单手挥动铜色细长刀斜向迎击。\
\
银色宝剑与铜色细长刀在镜头前猛烈擦撞，火星、雨水与芦花同时炸开。主角顺着碰撞力量从鸟妖身前快速穿过，鸟妖立即旋身追击，双方继续向右移动。\
\
镜头2｜侧方极速抖动追拍转斜前方近景\
摄影机先与两人保持侧方平行高速追拍，虚化芦苇连续扫过前景。\
\
鸟妖挥动铜色细长刀连续横切与突刺，刀锋划开雨幕。主角沿着倒伏芦苇滑步前进，俯身避过横斩，随后旋身从刀锋外侧穿过。\
\
摄影机迅速穿过一片前景芦苇，由侧方追拍切换到主角斜前方倒退跟拍。主角朝镜头方向高速移动，鸟妖从后方持刀逼近，人物与背景形成强烈纵深压缩。\
\
鸟妖一刀从主角肩侧掠过，主角侧头闪开，银色宝剑反手向后格挡。金属碰撞瞬间，摄影机快速下沉至腰部低机位，贴着两人的脚步与武器移动。泥水被连续踏起，红袍、白羽和芦苇在画面中高速交错。\
\
镜头3｜后撤诱敌转反向突进\
镜头切到中近景，主角面向鸟妖快速向后滑退，银色宝剑横在身前，双脚在泥水中拉出连续水痕。\
\
鸟妖顺势追近，单手挥动铜色细长刀连续压迫，最后高举细长刀向前下方斩落。摄影机跟随主角倒退，逐渐拉开两人的纵深距离。\
\
刀锋逼近的瞬间，主角突然停止后撤。镜头迅速推近主角侧脸，雨水沿脸颊滑落，眼神冷漠稳定。\
\
主角脚下猛然蹬地，身体由后退瞬间转为向前突进，从铜色细长刀下方贴身穿入。银色宝剑沿着刀身向上滑行，主角转腕发力，以一记干净迅猛的斜向上挑击中护手附近。\
\
铜色细长刀瞬间脱离鸟妖手掌，被挑向空中。鸟妖身体因惯性继续前冲，空手踉跄半步，白羽与长袍在风雨中凌乱扬起。主角持银色宝剑从鸟妖身侧穿过，动作保持连贯。\
\
镜头4｜铜色细长刀飞空与落地特写\
画面切到空中的铜色细长刀，角色退出画面。\
\
铜色细长刀在暴雨中旋转飞过灰暗天空，纤细刀身与暖铜色金属边缘依次掠过镜头，雨珠沿旋转轨迹向外甩散。摄影机跟随细长刀下坠，背景由灰黑天空逐渐过渡到翻涌的芦苇海。\
\
铜色细长刀斜落进泥泞地面，刀锋插入湿土，泥水与断裂草叶向外飞溅。镜头停留在低机位特写构图：铜色细长刀位于画面主体位置，刀身持续轻微震颤，前景芦苇被强风吹过，后景只有翻涌的芦苇原与暴雨天空。\

# 首批行为任务

使用已有材料，完整原文与实际输出留本地，不随本轮上传。每次独立执行只提供请求、Skill 与必要原件，不把预期答案交给执行者。复核者再依据下列标准评估。

| ID | 输入与任务 | 复核要点 |
|---|---|---|
| B001 | P024：把有视频／图片引用的独轮车提示词整理成文生版本，保持既有内容和视听要求 | 无悬空参考；不虚构未见图像信息；单轮动作、时间段、原配乐保持；不擅加首帧匹配或无音乐 |
| B002 | P037：只检查对白进程、镜内节拍和跨镜接续，不整篇改写 | 区分有目的重复和边界重复；抢话不是机械轮次；揭示时间容量与重复发声的具体风险；不擅改固定台本 |
| B003 | P053：按同一故事改稿，本次图仅约束女孩身份和服装，不匹配首帧 | 条件性“强调！”；移除旧首帧条件；不冻结表情；低位拾取、观察、台词与物理细节仍连贯；不添加剧情 |

这些任务只支持提示词行为结论。实际图像身份、口型、物理动作、方言、画质和转场效果另行生成评审；文字通过不能越级。

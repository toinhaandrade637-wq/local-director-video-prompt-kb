## 2. 开头建立观看方式

本批开头通常用少量文字给出画幅、影像质感、观察位置、摄影状态、是否连续拍摄及声音方向。微观贴地、在人群中踮脚、跟着人物移动、始终位于观众背后，会形成不同的遮挡与取景条件。

后文继续兑现这些条件：靠近什么、何时看清、何时被遮挡、摄影师怎样找回对象。手持幅度按场景选择，微距的极轻呼吸感与紧张记者的强烈晃动并不需要统一。某种观看方式被明确采用后，才在局部安排相关修正或对焦迟疑。

## 3. 材质与接触、受力、运动、声音相连

用户以气泡、磨砂、局部发白和糖霜等描述建立硬糖的具体质感。这里保留可见表现，不自行解释其化学成因。

进一步可按需要连接：

**物件的形状和材料 → 接触谁/什么表面 → 怎样受力 → 怎样移动或变形 → 留下什么声音和痕迹。**

P049把蚂蚁抓地、托推牵引与硬糖重量对应；切面交替触地带出卡顿、轻微偏移、重心变化与不规则磕碰。P050的幻想变化完成后，硬糖仍需落下、弹跳、碰撞、滚动，衣服因失去支撑塌落。P053则把捏取、离地、手指和糖表面的微小摩擦与人物谨慎观察联系起来。

细节应按镜头需要选择。微距可以容纳气泡、霜感与指甲边缘；较远机位着重重量、运动轨迹和声响。并非所有物体都要加磨损、灰尘、颗粒或气泡，选择应能区分目标材质并参与当前画面。

颜色也有局部关系：糖果可以保持自身颜色，实验空间仍为冷灰；主体与背景可通过明暗、饱和度、清晰度和尺度区分。全局“低饱和”不必抹平全部物件的颜色差异。

## 4. 摄影路径与注意力变化相互配合

P054先让观众在自然空隙里看见完整画作，再随不同发言者移动到肩颈后方，最后由一句台词触发对关键局部的变焦观察。画面中的说者、焦点对象、实际声音来源和观众需要发现的信息可以不同。

重要细节需要有辨认的机会：允许前景短暂遮挡、焦点先落偏，但最终必须明确落在要呈现的对象上，并保留相应停留。对焦游移是一种有范围的摄影行为，不能使关键证据始终不可见。

此处只记录提示词希望观察画作中什么，不核验未提供的参考图是否具有相应细节。人群最初朝镜头方向看，也不自动等于他们直视镜头；需要说明他们实际注视的对象。

## 5. 从A到B还可以按画面区域推进

P052为已有连续转场研究补充一种实现：移动的人和桶构成遮挡边界，已经被扫过的区域进入工厂，未扫过的区域继续保持美术馆及原来的人物活动。

需要写清五项：

1. 遮挡物从哪里进入，向哪里经过。
2. 哪部分画面已经变成B，哪部分仍是A。
3. 变化是否只发生在遮挡物经过的区域。
4. 转换中途两个空间及前中后景怎样同时存在。
5. 最后一部分被替换后，摄影机与场景处于什么状态。

原文还要求工厂中的另一名近景人物提前进入右缘，而右侧背景仍是美术馆。这可以按独立前景层与背景替换层区分，执行时应说明其进入路径和层次，不能用一句“右侧仍全是美术馆”覆盖掉允许存在的前景。

这个方法与母子案例的贴头遮挡/取景外变化不同，但共用“保持项、变化过程、中间状态、到达状态”。不是所有转场都需要左右分区，也不把一镜到底与数字转场排除项复制到普通剪辑段落。

## 6. 群体活动与信息揭示

美术馆观众共同看画，个体可偏头、整理眼镜、换位置或思考；实验人员共同等待，异常后有人退、有人成为静止观察者、有人出声。群体拥有共同任务，各人反应的时间、幅度和动作不必一致。

P050的场级发展是预期建立、行动发生、等待没有即时结果、群体疑惑、异常出现在另一个对象身上、政客重新解释结果。它依赖信息顺序和不同角色认识，不必额外加旁白说明。原文没有完整交代糖果化的唯一触发规则，研究时不替它补造因果法则。

## 7. 保留用户有效的明确强调句

2026-10-20用户纠正“强调！”后的感叹号；2026-10-23又澄清，首帧只是应用示例。后续整理按任务选择需要强调的对象，可以是人物身份、不可改变的特征、场景或有明确匹配要求的首尾画面，不能默认所有提示词都锁首帧。历史引文标点保持原样，通用表达为：

```text
强调！<当前任务中确实需要突出的具体要求>。
<必要时补明对象、参考来源、需保持的属性与生效阶段>。
```

例如，需保持人物身份时强调身份，需沿用场景布局时强调布局；只有明确要求首帧与参考图完全一致，才使用对应首帧句。模板不自动替用户缩小原本要求的一致范围，也不把人物一致扩大为动作表情静止，不把场景参考变为固定首帧。首尾画面确有要求时，仍要给出中间变化过程。强调句可放在相关内容附近，不必单独成栏。

这是保留用户经验的写法，不宣称这些词是模型硬权重语法、像素级保证，或能替代入口中的首尾帧角色设置。是否实际硬锁画幅仍按已记录的官方口径差异与实际入口处理。

## 8. 长写与简写的共同判断

上批构图与方言样例把许多信息交给明确参考，因此正文可以短；本批要新定义微观受力、观察路径和异常转场过程，详细文字承担更多任务。选择依据是当前精度和信息缺口，而非统一要求长或短。

这些补充仍并入现有骨架：开头定总体观看条件；局部把目的、行为、材质响应、摄影与声音连在一起；段尾留状态；必要位置重复关键要求。

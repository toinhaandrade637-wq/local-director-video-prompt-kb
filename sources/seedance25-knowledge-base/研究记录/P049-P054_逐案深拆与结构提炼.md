## P049：蚂蚁搬运透明硬糖

[原文](../资料库/01_用户提示词原文/P049_蚂蚁搬运透明硬糖_微观纪录片.txt)

### 原文怎样把一个简单动作写成可感知的现场

| 原文中的顺序与短引文 | 这部分实际承担什么 |
|---|---|
| “超低机位的微观纪录片视角”，贴近潮湿、带灰尘的地面 | 先决定观众所处尺度；后面的颗粒、触地和摩擦因这个观看位置而有意义 |
| 多支蚂蚁小队、不同颜色、“完整的半透明硬糖” | 建立主体组织、道具身份与尺度连续；完整硬糖区别于小碎屑，决定搬运的困难 |
| “细小气泡、磨砂纹理与真实糖霜感” | 用生活观察定义物件表面，支持近看的辨认；不只是再说一次“写实” |
| “底部托举、侧面推动、前方牵引” | 把集体搬运分成不同接触位置与作用方向，避免所有蚂蚁只围着糖走 |
| “腿部抓地……身体发力与糖果重量” | 把主体运动与被搬物的响应联系起来；触角与腿的活动不应取代发力过程 |
| 翻滚、偏移、“偶尔卡顿后重新滚动” | 让材料与地面阻力参与事件；卡顿不是动作失效，而是搬运过程的一部分 |
| “不同切面交替接触地面” | 给震颤、重心变化与咔哒声同一个原因，细节互相支持 |
| 橙红糖在前景，左右糖果与背景小队持续经过 | 确定主次：前景负责看清搬运，旁侧和远处证明这是多队共同工作 |
| 极轻呼吸感、浅景深、背景白大褂完全模糊 | 规定摄影观察的限制；人影只提供世界背景，不取得新的叙事中心 |
| 摩擦、磕碰、不规则“咔哒”及低底噪 | 声音随触地过程发生，让重量与表面粗糙度可以被听见 |

这例的关键关系是：**接触分工 → 合力 → 切面触地和阻力 → 队伍调整 → 继续移动，声音跟随同一接触过程。** 它不需要戏剧性反转，持续搬运本身就可以成为整段的发展。

### 要保留什么，哪些需要明确

完整硬糖、尺度稳定、不同接触分工、前景主要观察对象和滚动阻力应保留。气泡、糖霜、灰尘有用，是因为当前镜头接近这些表面；换成大全景时，可以把主要文字用于队伍路线与整体节奏。不能由此推导所有题材都必须添灰尘和颗粒。

“焦点主要锁在前景糖果与蚂蚁身上”之后又写“焦点再缓慢回到”，没有交代焦点曾离开哪里。蚂蚁靠近镜头边缘而虚化，也可能只是离开清晰范围，并不一定发生了主动调焦。这里是需要明确的过程，不是已证实的矛盾：究竟保持糖果焦点，还是先误对近处蚂蚁再回糖果，应在执行稿中选清。

“所有动作连续”与“偶尔卡顿”可以共存：前者指搬运过程不断线，后者指糖果阶段性受阻。若为求简洁删除卡顿，反而会失去重量感。“有明确方向”还未给具体银幕方向；只有后续镜头需要承接路线时，才必须补定。原文没有要求严格一镜到底，也没有总时长，不从其他案例移植这些限制。

### 可迁移的写法

适合小尺度搬运、推拉、攀爬、开合等以接触和阻力为观看重点的内容。迁移的是接触关系，不是蚂蚁、硬糖或固定浅景深。

以下只重排已有事实，示范一个综合小段，未经生成验证：

> 前景橙红色硬糖由数只蚂蚁从底部托举、侧面推动和前方牵引，蚂蚁抓地发力并随糖果的位置调整。糖果不同切面先后触地，向前翻滚时轻微偏移、卡顿，再重新滚动；细小震颤伴随不规则的咔哒和颗粒摩擦声。贴地微距重点看清糖果表面与蚂蚁足部，旁侧队伍和远处白大褂人影保留为背景。

## P050：实验基地与糖果化反转

[原文](../资料库/01_用户提示词原文/P050_实验基地观察与糖果化反转.txt)

### 事件、人物目的与观众认识一起推进

| 原文发展 | 行动与信息职责 |
|---|---|
| 写实、冷峻荒诞、延续试验基地世界观 | 指定呈现方式与续接关系；“之前”引用的内容仍需从已有资产或上文取得 |
| 跟随政客和跟班进入观察室 | 让观众伴随来访者发现现场；跟班小步跟随、观察政客、搓手强笑，服务于讨好而不只是“紧张” |
| 跟班说仍在验证触发条件 | 建立实验尚未被理解的预期，为结尾关于“结果”的分歧做准备 |
| 玻璃两侧、两名囚犯与椅子束缚 | 明确权力和行动条件：观察者安全在外，一人能够动手，另一人不能自由应对 |
| 分别看囚犯状态，再看空旷全貌 | 近处让恐惧可读，远处让无处躲藏可读；二者提供不同信息 |
| 第一次命令，囚犯看向玻璃求助 | 命令尚未转成行动，停顿和犹疑具有剧情作用 |
| “Hit him. Or...”与威胁性笑容 | 不说完的威胁改变囚犯处境，触发转向对方和道歉 |
| 道歉、挥拳、等待、“什么都没有发生” | 让预期落空明确成立；不能删成击打后立即爆裂 |
| 观察者失望，发令者刚要回头便变成糖果 | 异常发生在观众预期之外的对象上，打破原来的观看者与被观看者分工 |
| 糖果撞击、弹跳、滚动，科研服失去支撑 | 变化完成后，以物质响应证明发生了什么；衣服塌落和糖果声不是装饰 |
| 群体惊慌，跟班继续解释，政客说已有结果 | 不同人物对同一结果作出不同解释；政客的克制与现场混乱构成结尾张力 |

这例不能只记成“实验室、紧张、爆裂”。有效之处在于：**建立预期 → 迫使行动 → 等待落空 → 结果出现在另一处 → 人物重新解释结果。** 其中“命令迫使囚犯击打”有明确因果；击打、回头、糖果化之间仅有明确时序。文本没有公布糖果化的完整触发规律，不能替故事补写“施害者必然糖化”等结论。

### 摄影与声音要完成什么

前段侧后方跟行，后来多次切到不同人物，所以本例是多镜头内容。前段“始终贴着他们移动”应限定在跟拍段内，不能覆盖后面的独立观察机位。“所有角色陌生面孔”与沿用同一个政客身份也能共存：它没有要求每镜换一张新脸。

后段发令者背后机位很有作用：近处是科研人员与控制台，远处是玻璃后两名囚犯，焦点从观察者交给受试者。随后异常恰好发生在近处，执行时须安排让这一变化可辨的清晰度与取景。原文未说明回焦还是保留足够景深；不能仅因动作写得很详细，就当作必然已被看见。

话筒、玻璃、空调、压低的惊呼构成具体声音空间。内外切镜时，声音可随观看位置变化；从观察室听见囚犯呼吸，则需要理解为场景传声或该镜头的声音处理，原文未给唯一方案。宏观“真实收音”不能代替每个声音的来源判断。

糖果形状、环带、半透明硬质和大小是具体资产要求。它们可放入共享道具定义，变身小段重点写四散、碰撞与衣服塌落。幻想变化与变化后的重量规律属于不同层面，不必为追求写实删除变身本身。

### 重复与迁移

可以收拢反复的“极度真实”、冷峻荒诞和无音乐，也可合并同一时刻两遍解释跟班“讨好、勉强、局促”的句子。应保留他前段引导和末段失控后的继续讨好，因为这是同一人物目的在新处境中的表现。两次“Hit him”也必须保留：第二次附带“Or...”改变了威胁程度，不是冗余。

这套结构适合有预期、试探、误判和延迟揭示的剧情。迁移时先保住观众认识变化及人物目的，再决定摄影和声响；不要求所有反转都爆炸或让角色死亡。原文没有总时长，需要进入执行阶段再给完整台词、等待和反应分配时间。

局部重排示例，未经生成验证：

> 站立的囚犯道歉后，痛苦而颤抖地挥拳击中被束缚的囚犯。众人屏息等待，房间短暂安静，眼前没有出现预期结果，玻璃外的人开始困惑。发令科研人员刚要转头看政客，身体突然化成大量半透明硬糖炸散，科研服失去支撑塌落；硬糖接连碰撞桌面和地面，滚动声中，周围有人后退、有人僵住，压抑的惊呼随之出现。

## P051：发布会声明

[原文](../资料库/01_用户提示词原文/P051_发布会声明_记者一镜到底.txt)

### 这一镜同时控制讲话与观看

开头的一镜到底、记者手持、重大消息的现场压力，建立持续观看方式。logo极近特写先让机构标识可读；画面展开，经过耳侧到达发言人侧前方，再听她以亲切方式宣布制度。声明从尊重个体、否认限制与道德评判，转到“为了公众安全”，最后给出连续三次糖果化者将被选为“head sheep”的条件。详细台词各句职责见对白记录。

关键是内容发生转折而发言人的亲和态度继续保持。不能把“公布带条件的筛选安排”自动译成邪笑、压低声音或突然凶狠。说到“head sheep”时眼睛→logo→脸的焦点变化，把具体称谓重新联系到机构标识；这就是一次有内容触发的摄影变化。

### 四种摄影信息分别核对

1. logo极近特写是取景大小；它并未给定摄影机与屏幕的实际距离。
2. zoom out改变取景视角；从耳侧擦过、移到侧前方需要机位移动与朝向变化。
3. 踮脚、呼吸浮动和横向偏移规定摄影者的操作状态。
4. 眼睛与logo之间游移规定清晰对象的改变。

四者可以同时发生，但“后拉”不能包办全部过程。需要让连续路线能够绕开讲台和人物，同时仍将屏幕留在其身后。原文没有充分给出路线，属于待明确，并不据此断言一镜到底不成立。

### 保留条件与文字问题

开头指定“品牌logo”，结尾又说“无……品牌”，在相同默认范围内冲突。若意图是禁止额外品牌，执行稿可明确“保留指定标志，其他标识不新增”，但这只是待确认的修正方向，不能偷偷改原文。无字幕与现场LED文字则不冲突，二者来源不同。

短暂失焦可以保留，但开头logo的清楚完整和关键词后的脸部回焦需要真正成立。不要把“不断尝试对焦”扩大成全程不可读。原文没有视频时长，不能套用30秒等统一模板后再压迫自然语速。

可合并无新增作用的“真实、现场、纪实”重复；保留在关键词上再次指明焦点行为。适合声明、仪式、采访等态度与话语内容形成张力的段落。不是所有声明都需要手持、虚焦或可疑机构。

局部重排示例，未经生成验证：

> 发言人始终面向观众，以亲切、平静的语气继续声明。说到“head sheep”时，焦点短暂从她的眼睛游移到背景logo，再勉强回到脸上；她的神情没有随这个称谓突然改变。画面保留记者在人群中拍摄的上下浮动和横向偏移，快门、衣料摩擦、低语及空调声延续。

## P052：美术馆逐区域变为桶厂

[原文](../资料库/01_用户提示词原文/P052_美术馆到桶厂_逐区域遮挡转场.txt)

### 先后状态是这个转场的主体

| 阶段 | 摄影看到什么 | 正在保持与变化的条件 |
|---|---|---|
| 画中手部局部 | 画布、颜料与色块，左前景男人虚影 | 仍在美术馆；局部停留约3秒 |
| 展开空间 | 完整画作、背向镜头的观众 | 观众各自微动，摄影保持手持观察 |
| 工人拖桶入画 | 人和桶从左往右移动 | 桶摩擦地面；经过的位置开始显露工厂 |
| 中途并存 | 左工厂、中央拖桶者、右展厅 | 尚未经过处仍有人看画，变化不能提前覆盖整个背景 |
| 前景层加入 | 右缘另一工人的近侧脸和面罩 | 原文要求其与右侧美术馆同时可见，需明确独立前景层 |
| 转换结束 | 拖桶者右侧出画，工厂完整成立 | 工人各自登记、检查、推车、核对，环境继续活动 |
| 指定尾帧 | 图3定义的结束画面 | 必须与首帧图1共同约束路径的起止，不能省略到达过程 |

它给“从A到B”增加的内容是：**不仅规定变化前后，还规定中途已变区域、正变化边界、未变区域及其各自仍在发生的事。** 这使转场成为一个可以观察的过程。金属桶同时承担动作、遮挡与声源，工人的移动因此不是无来由的转场符号。

### 必须说清的两个空间问题

第一，右侧未变化的展厅与右前景工厂人员可以按不同深度层并存，但原文“只有被他走过、遮挡并带过的区域”没有说只约束背景。若该规则约束全幅所有层，前景工人提前进入就会与它竞争。可以选择“背景按边界替换，近前景人物独立经过”的解释，但须在执行稿明确，且补清进入路径；本研究不替原文默认做了这个决定。

第二，人和桶实际遮挡的轮廓未必覆盖天花板、墙上方和肢体间隙。需要区分“真实轮廓挡过的位置才显露新空间”和“人员走过后的一整条区域都变化”。两种视觉规则都能创作，呈现方式不同。不能只写“自然”来跳过上部画面怎样完成替换。

超长焦与“紧贴画作”也要分开理解：可以是紧构图，不必是机位贴着画布。zoom out与后退可以协同，但不能互相当作同义词。观众后脑、画作、拖桶者、近前景面罩的距离层次应支持规定取景。

### 声音、调色和重复

声音已有旧空间交谈与脚步、连续桶摩擦、新空间机械声。还可以在执行时明确机械声何时进入，旧空间声随保留区域怎样退去，避免画面分区已建立而音轨突然整段换场。这是过程细化方向，不是原文已经完成的声音调度。

展厅和工厂有不同光源与空间色彩，变化区与保留区应各自保持当时受光。自然曝光变化不是任意让全部画面同时改色；也不要求逐区域转场一律使用相同色彩。

中途再次强调右侧仍为展厅很有功能，它定义未变化状态；“无fade、无溶解、无跳切”可集中成同一处边界。近景面罩、工业雾和失焦若遮住了变化边界，就会削弱主事件。本例原文确有首尾画面匹配要求，可按“强调！”的写法表达，不缩成仅采用人物或色彩：

> 强调！首帧画面必须和图片1完全一致。尾帧画面必须和图片3完全一致。

这句为本例需求下按最新标点偏好整理的写法，不是改动原文，也不是其他任务的默认首尾要求。参考图未提供，本轮不能核对图中实际构图。

迁移适合环境、年代、状态等需要连续显露的改变。继承“谁触发、哪里已变、哪里保持、中间如何共存、最后怎样完成”，不必继承工人、桶或左右方向。

## P053：女孩捏起黄色硬糖

[原文](../资料库/01_用户提示词原文/P053_女孩捏起黄色硬糖_贴地微距.txt)

### 一个小动作也有目的与表演发展

原文的顺序是：首帧落在地面硬糖 → 女孩俯身进入 → 在糖果和周围间确认 → 谨慎伸手 → 两指捏住同一颗黄糖 → 举到眼前端详 → 困惑与不安加深 → 耳语“Candy?”。

“好奇”使她伸手，“隐约恐惧”使她谨慎，“困惑”使她继续端详和询问。三种状态不是要求一张脸同时堆上三套夸张表情，它们分别影响行动的方向、速度和后续反应。此例最直接回应用户所说“每个角色怎么运动、目的是什么”：动作虽小，不能只剩“女生拿起糖果”。

| 细节 | 当前作用 |
|---|---|
| 地面黄糖最清晰，少女从上方俯身 | 建立被观察的物件与观察者之间的空间关系 |
| 目光来回确认、轻呼吸 | 使犹疑发生在伸手以前，给动作动机 |
| 指尖接近镜头变得巨大 | 同一手指在近距离透视中显得更大；不是手掌真的变形 |
| 两指捏取前景中央同一颗黄糖 | 固定动作对象、抓取方法和道具连续性 |
| 糖霜、磨损、灰尘、细小皮肤纹理 | 在靠近时提供可辨材质，不承担独立故事事件 |
| 离地摩擦、衣料与呼吸 | 让动作克制且有接触；声音不必靠音乐说明神秘感 |
| 透过糖端详，再说一个疑问词 | 视觉辨认先发生，语言是对辨认结果的不确定确认 |

### 需要落实的观看条件

首帧黄糖在地面，结尾黄糖在眼前，两个位置不能靠“焦点最清晰”一条全局话覆盖。固定贴地机位可以保持，但需要让抓取、举起与端详先后进入可见范围，并决定清晰对象何时由地面糖果交给手中糖果及眼睛。原文尚未给出明确焦点交接，属于可细化处。

“神情更困惑、更不安”只在脸部足够可辨时成为画面信息；如果焦点和构图仍紧贴指尖，就应让当前可见的迟疑、呼吸承担表演，或另安排对脸的观察，不能只写微表情却不给看见它的机会。当前原文没有要求切镜，不能为补清楚而擅自插入新镜头。

开头写实、结尾不要广告感可以收拢；结尾再次确认“镜头保持贴地”有功能，防止人物拿起糖时摄影机自动跟着升高。“一镜到底”只在本例生效，不因此成为所有拾取动作的必选形式。

迁移适合检视、触碰、试探、拾取等目的明确的小动作。可保留“注意与确认 → 接近与接触 → 道具状态改变 → 检查 → 轻声判断”，没有判断台词时可停在动作或眼神。

局部重排示例，未经生成验证：

> 女孩俯身看着地面糖果，目光先在糖果与周围之间来回确认，呼吸很轻。她缓慢把拇指和食指伸向前景中央的黄糖，近处指尖因透视显得巨大，随后小心捏起它。糖果离地发出细微摩擦；她把同一颗糖举到眼前端详，困惑和不安加深，几乎耳语地问：“Candy?” 镜头保持贴地低角度。

此段只展示目的、动作、材质和声音怎样相连；明确焦点交接仍属执行时待处理项。

## P054：美术馆群像讨论

[原文](../资料库/01_用户提示词原文/P054_美术馆群像讨论_说者与画作细节.txt)

### 同一对象被逐步重新理解

1. 先看观众认真观察的脸与动作，让“他们在看什么”成为问题。朝镜头方向看并不等于看镜头，他们实际看的是画。
2. 摄影机绕到后方，短暂完整显示画作，回答“看什么”；随后人群重新部分遮住，规定接下来观看会受现场身体阻隔。
3. 女生提问，男生给出快乐的解释；说完才意识到不合时宜，笑容收起并轻咳。这是行动后的自我修正，不是无缘无故改变表情。
4. 后续人物分别说连接、人与人的连接、循环；他们共同看同一对象，各自提供不同程度的理解。
5. 留胡子男人承接这些解释，提出圆环并不完整。特定词语触发zoom in，镜头将抽象解释落实到两只手的间隙。
6. 画面停在证据上，男人继续画外说明，观众有时间辨认；说完再zoom out回到群体，沉默成为新的理解状态。

这例最有用的学习是**注意力顺序可以不同于说话顺序**。最后发言还在继续，画面已经以细节为中心。固定“谁说话就一直给谁近景”反而可能破坏作者原来要完成的揭示。

### 空间、表情与焦点核对

初到后方的无遮挡全貌、随后人群遮挡、结尾完整尺寸但被挡一部分，是三个不同阶段，不矛盾。开头“镜头前方的一幅画”却容易与镜头正对观众混淆，执行时要明确画相对摄影机的实际位置。绕过人群与各说者之间移动也需要可通行路径，不等于镜头可以穿过身体。

说话者身后的帽子、颈部、肩膀提供近身观察感。西班牙女生段特别写了偏到侧面，因而有看到侧脸的条件；其他始终在后脑的取景，不必然看清笑容收起或羞怯神情。可以由已经规定的轻咳、头部动作和声音表达部分状态；若要求视觉辨认，就须给出可见角度。不要把“想让人物表现”与“观众已经看见表现”混为一谈。

文末“每当有人说话”都近拍颈头的总则过宽，与后段持续拍手部间隙的局部要求形成执行竞争。即使把它理解成先到说者背后再观察画作，也应明确例外：关键细节已经进入时，台词可继续在画外。此处优先澄清作用范围，不用全局句抹去已有局部安排。

间隙是最终证据。衣领误对焦与之后回到画作表现寻找过程，但必须回到可辨状态并停留。关键阶段需要的不是更多游移，而是确切看清。前面的失焦描述可以按主要触发点收拢。

### 声音与迁移

各说者的语气、轻咳、停顿和口音有不同功能。口音不能只由族裔标签推定；原文“亚洲女孩口音明显”还没有指定哪种语言背景，若发音是关键控制，应另行确定。Pan和“最近发生的事”引用外部剧情，本例不够推断其完整设定。

迁移适合从群体反应到共同对象、再到关键细节的观察和发现过程。保留话语触发、视线受限、证据停留与发现后的状态；不把国籍组合、人数、具体作品或一镜到底列为通用固定项。

局部重排示例，未经生成验证：

> 留胡子男人说到“isn’t complete”时，镜头从他背后穿过肩膀间的视线缝隙，长焦zoom in到两只差一点碰到的手。男人的虚影留在前景边缘；焦点先短暂落在衣领，随后回到两手间隙并停留数秒，让这一细节清楚可辨。他的后半段台词继续时，画面仍停在间隙；台词结束，再zoom out回到看画的人群。

## 跨案例关系与不能直接套用的部分

P052写画中“相握的手”，P054写“没有相握”的手。二者可能选择画作不同局部；如果要把它们直接接成同一局部的连续镜头，就需确认观察对象是否变化。仅凭作品同名不能宣称衔接已成立，本轮也未核对实际画作或参考图片。

糖果在数例中承担不同职责：被搬物、身体变化后的结果、被检视的证物。共享资产定义可以避免重复设定，但材质描写应按当前距离与用途落实。若作为同一世界连续片段，须核对尺寸、形状和表面状态的版本；不能把一例的局部特写要求机械复制到所有远景。

本批没有统一的时长，只有个别“约3秒”“数秒”等局部要求。不能因为前面不少案例是30秒，就给这六条自动补成30秒，也不能据文本长度虚构已完成的朗读与调度时长验证。

## 对通用结构的实际修订

共同骨架仍是：**生成目标/一句概述 → 素材对应（有则写）→ 全局设定与本场发展 → 逐镜或连续阶段的综合小段 → 必要补充。** 本次不再添加一套题材专属栏目。

局部写作时，可以在内部依次想清下列关系，再写成连贯小段：

> 承接什么状态；人物要做什么、为什么；什么触发动作或反应；接触和运动改变了什么；摄影机怎样让关键过程可见；相关环境、光色和声音怎样响应；段尾留下什么。

这不是每段八项填空。蚂蚁例不必硬写人类情绪；声明例不必硬塞物理冲击；固定观察可以保持状态，不必安排转折。每一小段只选择当前有效的关系。

详细与精简用同一个标准判断：该句是否新增对象、范围、触发、路径、可见结果、状态或区别。糖果切面与卡顿、动作发力与重量、关键词与焦点转移属于有效细节；反复说“极度真实”而没有新增过程，才是应合并的重复。

“强调！”按任务突出重点，正文再说明该要求如何在相应过程里落实。需要身份或特征一致时保持对应属性，动作和表情仍可发展；只有指定首尾画面时才落实对应的到达状态。核心强调、局部细化、跨段承接可以同时存在，不能为了去重复把三者全部删成一句口号，也不固定生成一段首帧强调。

审美也落实在关系上：材质如何受光、主体与背景怎样分离、哪部分饱和度更高、哪部分明度维持较低、转场前后哪些区域已经改变。数值和术语只有在确有控制需要时加入，不自动给所有作品套低饱和、颗粒、冷调或电影机型号。

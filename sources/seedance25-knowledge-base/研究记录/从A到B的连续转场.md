# 从A到B的连续转场

更新：2026-10-24

用户明确认可P002与P003两个母子案例的转场，认为适合“什么到什么”的表达。以下为从认可案例中归纳的方法，具体通用写法仍可继续打磨。

原文：[P002 街道到熔岩火山](../资料库/01_用户提示词原文/P002_母子街道转熔岩火山_三镜版本.txt)、[P003 街道到秋日山谷](../资料库/01_用户提示词原文/P003_母子街道转秋日山谷_连续行走版本.txt)。原文不修改。

## 核心关系

明确A与B各是什么状态，再安排人物行动、摄影路径、变化过程和新状态的显露。两例的主要连接是同一个男孩张开双臂持续前进，摄影机随行、贴近、环绕，再拉开升高，世界在这个连续过程里改变。

可提炼为：**A中的持续行动 → 变化介入 → 局部遮挡或取景范围外完成部分变化 → 逐步显露B → 行动在B中继续。**

这套关系适用于需要连续感的场景、时代、造型或现实与幻想转换。它是通用结构中可选的转场模块，不替代普通切镜、时间省略或平行叙事。

本轮八份Word讨论补充一个选择前提：先判断A到B属于既有空间中的行进、世界状态改变，还是时间省略。这里只吸收经验，不收录这批原文。

| 关系 | 过程需要说明什么 |
|---|---|
| 沿既有空间前进 | 同一路线中路面、植被、光线和声响怎样逐渐变化；人物位置确实在推进，不必遮挡换景 |
| 世界状态改变 | 场景、身体、造型或规则在哪里变化，哪些条件持续，怎样显露结果 |
| 时间省略 | 新镜头已到什么时刻，继承哪些结果；黑场、叠化或声桥不自动证明具体过去了多久 |

例如干路进入湿谷，可以沿一条可追踪道路渐增草叶、苔藓、水痕与浅涧，干土脚步逐步变为湿石和溅水声。它体现位置推进，不要求世界在人物经过时才被创造。夜晚切清晨则核对是否省略一夜，不能默认只是同一瞬间更换光色。

## 两例如何对应

| 维度 | P002 熔岩火山 | P003 秋日山谷 |
|---|---|---|
| 场景起止 | 暮色街道到熔岩与火山群 | 暮色街道到暖色秋日山谷 |
| 持续行动 | 张臂、低头、认真向前走 | 张臂、原方向、匀速前进；关键阶段再次确认 |
| 变化介入 | 上涌强风掀起头发，火星进入不同距离的画面 | 强风掀起头发，枫叶经过近景和脸侧 |
| 部分变化的隐藏位置 | 后脑与肩部遮住大部分环境时改变服装与书包 | 贴近头部时，装备在取景范围之外改变 |
| 路线关系 | 白线位置由悬空铁索承接 | 白线延伸方向由悬空藤蔓承接 |
| 逐步显露 | 装备、肩旁空间、双腿与铁索、火山全貌 | 侧脸与新背景、装备、全身与藤蔓、山谷全貌 |
| 表演 | 保持专注和行走节奏 | 侧脸显露时从认真紧绷转为开心期待，脚步继续 |
| 光线与声音 | 冷暮光转为熔岩暖反光；街道声转为强风与低沉轰鸣 | 冷暮光转为暖色逆光；街道声转为山谷风与叶声 |
| 结束 | 人物变小，仍沿铁索前进 | 人物变小，仍沿藤蔓前进 |

两例的连续转换发生在指定镜头内部，前面的镜头仍可以硬切。P003原文保留了“锁链／藤蔓”等版本混用，归档不修订；这里按其主要画面描述分析路线对应。

## 写新转场时需要确定什么

1. **从哪里到哪里。**写清A和B的场景、人物状态及关键差异，不能只用“梦幻转场”代替过程。
2. **什么持续。**选择能连接前后的行动、姿态、运动方向、关注对象或声音。两例用持续行走，其他内容不必都用走路。
3. **什么先出现、什么后显露。**新世界的风、颗粒、光线或声音可以先介入；空间、装备与支撑面按取景变化显露。
4. **变化在哪里发生。**这些案例采用遮挡及取景外变化；需要直接展示变化的任务则另写可见过程，不能一律藏起来。
5. **摄影机怎样完成揭示。**人物移动与摄影机路径分别成立；环绕角度、推近、后拉和升空按任务选择。
6. **何时可以看出已经到达B。**通过新的环境、造型、脚下支撑、光声关系等明确成立。到达B后可以继续行动，不必站定摆出结尾画面。

B首先是目标空间与状态。若环境参考图只提供元素、色调和光照，新构图仍应由当前摄影路径组织，不能默认把参考图作为转场后的固定画面插入。

删去转场中的某个阶段后，重新检查保留段怎样接上，尤其是物件何时取得、造型何时改变、声音从何处接续。已弃用的过渡不再作为当前要求，但原先由它完成的交接也不能被当成仍然存在。是否需要补过程、允许切镜或采用时间省略，依据当前目标确定，不擅自补造剧情。

## 可嵌入正文的自然段骨架

```text
起初，<主体>在<A环境>中保持<当前行动与状态>，摄影机<当前取景与运动>。
随着<触发或变化介入>，<新环境的可见、可听特征>开始影响人物和画面。
摄影机继续<路径>，在<遮挡、取景外区间或可见变化过程>中，
<需要改变的部分>逐步成为<B状态>；<贯穿行动、方向或其他保持项>持续。
随后<取景如何展开>，依次显露<证明B成立的内容>，
人物受光、物体反射与声音相应过渡。
结束时，<B中的明确画面与人物状态>，<行动继续或其他指定结果>。
```

这段可按主要发展拆为数个综合小段；动作、表情、镜头、环境与声音仍在各段相邻组织。表情可以变化，也可以保持：P002和P003恰好提供这两种选择。环绕、遮挡、情绪变化和升空不作为所有转场的固定套装。

## 与本场发展总控的关系

本场总控确定“从A到B”对本组有什么作用、哪些情绪或任务保持、结束落在哪里；转场小段负责把这个方向写成连续发生的画面。场景到达B与人物情绪到达某种状态可以相关，也可以分别安排。

## 新增：按区域推进的遮挡变化

P052美术馆到桶厂提供另一种实现：移动遮挡物由左至右经过，已扫过区域进入B，未扫过区域保持A，中途两个空间同时可见，最终完成替换。除了起点和终点，需要写清替换边界、前中后景层次，以及中途仍在原空间活动的人物。它与母子段的取景外变化共用连续状态原则，不必使用相同环绕方式。详见[代入感、材质响应与逐区域转场](代入感、材质响应与逐区域转场.md)。

# 构图参考分工、动作接镜与对白留白

更新：2026-10-19。来源为P044—P048五次原文出现，见[资料库索引](../资料库/索引.md)。P044、P046、P048属于同一拉钩约定的重复或引用形式变体，P045为万花筒争夺，P047为打赌激将。保留出现顺序，不推定它们是用户确定的最终成片顺序。2026-10-19用户明确补充：这批还应提炼方言对白的写法。

当前只有文字引用与部分资源数量/role标记，没有实际图像、音频或生成结果。未核对台语台词和罗马字发音的正确性，未把重复文本算作多次独立效果验证。

## 1. 参考资料承担不同层次的信息

| 参考类型 | 此批承担的职责 | 文字仍需交代的内容 |
|---|---|---|
| 人物图 | 身份与外貌 | 当前姿态、动作、表演与持续状态 |
| 道具图 | 万花筒等物件的外观 | 谁持有、怎样使用、如何交接、是否在本片出现 |
| 环境图 | 场景外观与空间依据 | 对岸方向、人物与场景关系、当前观看范围 |
| 标记位置图 | 标记1、2对应人物站位 | 谁站、谁蹲，局部运动后位置如何变化 |
| 小人构图图 | 机位、画幅关系与遮挡 | 小绿人、小蓝人分别对应谁，只继承指定构图信息 |
| 音色参考 | 各说话人的声音参照 | 谁在何时说哪句、语气、画内外来源 |
| 台词与拼音 | 同一句话的内容和发音提示 | 说明两种文字如何对应，避免被理解成两段顺序朗读 |

小人颜色属于示意标记，不自动变成成片人物的肤色或服装。输入数量和reference_image等标签只是本条提示所声明的资源配置，不证明本项目已取得这些文件，也不自动意味着硬锁首帧。

## 2. 图号和音频号只在当前提示词中解释

拉钩版本中Image3指人物，万花筒版本中Image3指道具；Audio1、Audio2也应按各组对应关系核对。不能因为一组里某编号对应某角色，就把它自动沿用到另一组。

可以先为当前组建立稳定角色名与编号对应，再在镜头中使用角色名或清楚的引用。转换花括号写法、纯编号写法或平台实际绑定方式时，保留对应关系；不能只替换文字外观却默认平台绑定已经完成。

## 3. 场景方向、人物姿态和观察机位分开

“两人面朝对岸”描述场景中的基准朝向；“转头看同伴”是局部表演；“正拍、背拍、过肩”是摄影机观察关系。正面机位可以通过摄影机换侧获得，不必让人物为镜头转身。

如果本段让一人转向另一人，需要明确是眼神、头部、上身还是整个身体变化，以及两人的位置是否仍沿用标记。参考图负责构图时，文字继续说明动作怎样发生，不能只用“空间正确”替代关系。

## 4. 接镜继承动作进度与持物状态

万花筒片段的连续过程为：原持有人举看 → 另一人起身抢夺 → 取得并试用 → 塞回 → 原持有人重新举看。不同镜头承接同一动作进度，不把抢夺在新镜头从头再做，也不让物件凭空换手。

打赌片段的蹲姿、起身和对方后退互为前因后果。镜头切换时写必要的接续状态即可，无须每镜重新列出完整流程。

资产排除项也有范围：本组不出现某两个道具，不等于其他组也不能使用这些图号。用于当前片段时，保持可见、不可见、暂未出现和不采用的区别。

## 5. 说话者、被观察者与焦点可以不同

这批常让摄影机观察听者，说者留在前景或画外。听到一句话结束、一个条件或某种确认后，才发生转头、眯眼、起身或思考。

P047末镜先看说话者，再把焦点交给前景开始思考的人，随后由他回应。取景不一定重组，注意对象已经改变。

拉钩片段在手部动作完成后，从近处的手移焦至对岸小岛。这个结束状态把注意力交给双方共同谈论的地方，允许停留和留白；不需要自动补全景、反应特写、字幕或另一个剧情事件。

移焦说明清晰对象、逐渐虚化对象以及最终落点即可；不能把转焦自动写成切镜或机位移动。

## 6. 参考明确时保留简式逐镜

这些提示词没有重写每张图中的建筑、衣料或人物五官，但以构图来源、空间关系、动作承接、台词和声音归属承担了必要信息。可作为既有“综合小段”的简式展开，不另建一套只适用于此题材的模板。

```text
当前组引用关系与空间基准。
镜头：观察方式/构图来源；承接的姿态或持物状态；
当前动作与对白；被触发的反应；焦点或动作结束状态。
必要的声音与排除范围。
```

需要更精细的情绪、环境或摄影控制时，再在对应镜头补写缺口。充分的参考可以承担世界信息，文字仍要让当前事件成立；无参考时则需要补齐必要外观与空间。

## 7. 原文保留，另记待厘清点

- P045前置说明人物半蹲，镜头二写坐在地上，需确定起始姿态或是否存在中间动作。
- P047镜头四写“同镜头3”，同时改变构图参考和被观察人物，需确定“同”指机位、连续拍摄还是仅承接事件。
- 多处全局“均面朝对岸”和局部“面朝另一人”须分清身体与头部朝向的作用范围。
- P045镜头五承接句出现“人物塞给道具动作”的指代形式，后文又明确原持有人重新举起，执行时需要把交出者、接收者与物件写清。

以上是从文字可见的指代与连续性问题，不据此判断成片失败，不修改原文，也不校正或重译台词。导演风格名称可保留为审美参照；本次结构归纳来自具体空间、表演和镜头组织，不把姓名当作唯一执行说明。

## 8. 方言对白：内容、发音、音色与表演分工

用户明确指出方言是这批的另一项可迁移信息。可在已有声音组织中细化，不另设所有视频必须使用的固定模块。

| 层次 | 要明确什么 |
|---|---|
| 方言选择 | 指定目标方言，确有需要时再限定地区变体或说话习惯 |
| 台词内容 | 使用符合角色和场景的具体词句；区分固定台本与允许翻译/改说的意图 |
| 发音辅助 | 汉字、罗马字或其他标注与相应台词配对，服务同一次发声，不当作第二份对白 |
| 音色参考 | 哪个角色参考哪段音频，以及借用音色、发音或其他哪些属性；这些职责分别说明 |
| 当场表演 | 逗弄、迟疑、恼怒、安抚等目的怎样影响重音、停顿、语尾、呼吸与抢话 |

方言表达需要兼顾用词、句式、发音和当下语气。不能仅凭写有方言名称、拼音或音频引用，就认为对应发音与口型已经验证。

```text
<角色A>用<目标方言及必要地区变体>说：<确定台词>。
<音频1>提供该角色的<音色或明确指定的语音属性>。
发音辅助：<与这句话配对的标注，供同一次发声参考>。
说话时承接<动作/目光>，在<词或对方反应>处<重音、停顿或交接>。
```

字幕、画面文字仍单独决定，不默认显示罗马字，也不要求人物把两套文字连续念两遍。需要精确发音时以已经核对的台本、标注或语音为依据；本批原文的台词与拼音继续原样保留，正确性不在本次归纳中擅自认定。

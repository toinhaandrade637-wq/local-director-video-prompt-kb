## 5. 三条推荐阅读路径

### 人：第一次用（15 分钟）

```text
START-HERE → README → catalog/higgsfield-projects.md（随便挑一个项目）
→ sources/higgsfield/projects/<项目>/README.md
→ tools/kb.py search --project <项目> --limit 5
```

### AI：接手一个写提示词的任务（5 分钟）

```text
AGENTS.md → docs/02-任务路由.md → 对应方法页 1–3 篇
→ catalog 检索 2–5 条 → 回读原文 → 写 → 自检 → 引用
```

### 维护者：改动后验收（10 分钟）

```text
docs/06-维护与更新.md → python tools/build_catalog.py
→ python tools/validate_kb.py → docs/08-构建与校验报告.md
```

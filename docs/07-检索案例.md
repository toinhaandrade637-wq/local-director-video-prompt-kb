# 检索案例

> 8 个真实查询，从“我要什么”到“命令”到“结果”到“下一步”。所有 ID 都在本库可复现。

## 案例 1：我知道 ID，只要全文

```bash
python tools/kb.py get --id VPL-sd2-259
```

输出开头：

```text
# 雪地女特工·近身搏斗
# /动作·打斗/近身·格斗 | Seedance 2.0

激烈的近距离格斗片段。主体：身着冬季战术装备的短发女特工……
```

**得到什么**：173 字的完整单条提示词，含主体、动作、物理效果、镜头、质感。

**下一步**：这是“零件型”短提示词，适合学动作与受力的写法；不要把它当整场分镜。

## 案例 2：只记得一个画面关键词

```bash
python tools/kb.py search --keyword "霓虹" --limit 3
```

输出：

```text
HFX-DETOUR-000166  Higgsfield  DETOUR  scenes  video  seedance_2_5  3722
HFX-DETOUR-000168  Higgsfield  DETOUR  scenes  video  seedance_2_5  2698
```

**得到什么**：DETOUR 里两条带霓虹街景的 8 秒镜头，都是 21:9、三镜连续。

**下一步**：

```bash
python tools/kb.py get --id HFX-DETOUR-000166
```

读完整段落，学它怎么把“霓虹招牌位置”写成可执行的画面约束。

## 案例 3：我要某项目里的分镜视频提示词

```bash
python tools/kb.py search --project DETOUR --cat scenes --type video --limit 2
```

输出：

```text
HFX-DETOUR-000001  ...  scenes  video  seedance_2_5  7216
HFX-DETOUR-000002  ...  scenes  video  seedance_2_5  4555
```

**得到什么**：DETOUR 有 706 条 `scenes`、509 条 `characters`、304 条 `locations`、263 条 `props`，是分类最完整的项目之一。

**下一步**：先读项目 `README.md` 和 `brief.txt`，再按 `line` 顺序抽读 5–10 条，理解整场戏的推进。

---

## 案例 4：查不到，因为项目没有分类

```bash
python tools/kb.py search --project KOK_BORU_FILM --cat scenes --limit 2
```

输出：

```text
没有匹配。
  提示 1：611 个项目里只有 6 个带 scenes 细分，537 个只有 all。
         先去掉 --cat 再试，或改用 --keyword。
```

**为什么**：KOK_BORU_FILM 上游只有一份 `_all_prompts.jsonl`，2,436 条全部归在 `all`。

**正确做法**：

```bash
python tools/kb.py search --project KOK_BORU_FILM --cat all --limit 2
```

得到 `HFX-KOK_BORU_FILM-000001`，5,491 字的定格手绘动画风格设定。

**教训**：`--cat` 不是万能筛选器。先看 [catalog/higgsfield-projects.md](../catalog/higgsfield-projects.md) 的「分类覆盖」节。

## 案例 5：我要一个超长的 Seedance 2.5 完整段落

```bash
python tools/kb.py search --model seedance_2_5 --min-length 6000 --limit 2
```

输出：

```text
HFX-ANERNEQ-000001  ...  all  video  seedance_2_5  8156
```

**得到什么**：极夜环境里生火的 8,156 字完整提示词，含光线、材质、动作、声音。

**下一步**：这类长文适合拆段学“环境 → 动作 → 结果”的组织方式，不适合整段套用。

## 案例 6：我要一组成片级的中文动作提示词

```bash
python tools/kb.py search --source vpl --zone 主库 --cat "动作·打斗" --limit 3
```

输出：

```text
VPL-sd2-259  VPL  主库/动作·打斗/近身·格斗  Seedance 2.0  173
```

**得到什么**：主库里按题材分好的成片级提示词，带中文标题、标签、模型。

**下一步**：`get` 读原文；需要更多同类，把 `--limit` 调大，或加 `--sub "近身·格斗"`。

## 案例 7：我要补运镜零件，不是整条提示词

```bash
python tools/kb.py search --source vpl --zone 通用区 --cat "运镜词典" --limit 3
```

输出：

```text
VPL-gen-001  VPL  通用区/运镜词典/固定机位 · Static  未标注  471
```

**得到什么**：单条运镜描述，可以直接嵌进当前提示词的摄影段。

**下一步**：按 `sub` 分组浏览（固定机位、推拉、摇移、变焦、特殊），一次只取 1–2 条，避免堆砌。

## 案例 8：我要找很短的镜头句，做节奏参考

```bash
python tools/kb.py search --max-length 300 --limit 3
```

输出：

```text
HFX-100_MILLION_RAT-000001  ...  all  64  remove and erase the necklace...
```

**得到什么**：64 字的局部修改指令，属于“资产重跑”类，不是叙事镜头。

**下一步**：这类短句适合学“一句一个动作”的写法；不要误当完整分镜。

## 案例 9（反例）：一次读太多

```bash
# 不要这样做
python -c "import gzip;print(gzip.open('sources/higgsfield/prompts/DETOUR/prompts.jsonl.gz','rt',encoding='utf-8').read())"
```

**为什么不行**：DETOUR 一个项目就有 2,173 条、约 9 MB 原文，读完会挤掉真正需要的方法页与任务上下文。

**正确做法**：`search` 定位 → `get` 取单条 → 需要时读邻行 1–3 条。

## 查询写法速查

| 我想要 | 参数 |
|---|---|
| 按片找 | `--project DETOUR` |
| 按素材类型找 | `--cat scenes` / `characters` / `locations` / `props` / `assets` / `all` |
| 按图片或视频找 | `--type video` / `--type image` |
| 按模型找 | `--model seedance_2_5` / `--model default` |
| 按长度找 | `--min-length 3000` / `--max-length 400` |
| 按关键词找 | `--keyword "霓虹"` |
| 只在多模型库找 | `--source vpl` |
| 按分区找 | `--zone 主库` / `通用区` / `教程区` |
| 按标签找 | `--tags "微距,FPV"` |
| 限制条数 | `--limit 20`（默认 20） |

组合原则：**先窄后宽**。先 `project` + `cat`，无结果再去掉 `cat`，最后用 `keyword`。

# 检索手册

> 目标：用最少的上下文，拿到最准确的那一条。核心是“**先索引，后回读**”。

## 1. 两个索引文件

| 文件 | 行数 | 每行是什么 | 用途 |
|---|---:|---|---|
| `catalog/higgsfield-prompts.index.jsonl` | 174,404 | 一条 Higgsfield 提示词的定位信息 | 找项目内某条提示词 |
| `catalog/video-prompt-library.index.jsonl` | 977 | 一条 VPL 条目的定位信息 | 找主库/通用区/教程区条目 |

两个文件都**不含提示词全文**，只含 80 字摘要，可以放心用编辑器或 `rg` 搜索。

## 2. 索引字段

### Higgsfield

```json
{
  "id": "HFX-DETOUR-000123",
  "project": "DETOUR",
  "cat": "scenes",
  "type": "video",
  "model": "seedance_2_5",
  "len": 7216,
  "line": 123,
  "head": "Suspenseful action vibe..."
}
```

| 字段 | 含义 | 可用来筛 |
|---|---|---|
| `id` | 稳定 ID：`HFX-项目-六位` | 精确取全文 |
| `project` | 611 个项目之一 | 按片找 |
| `cat` | `scenes` / `characters` / `locations` / `props` / `assets` / `cover` / `all` | 按素材类型找 |
| `type` | `video` / `image` / 空 | 按图片/视频找 |
| `model` | `seedance_2_5`、`default` 等 | 按模型找 |
| `len` | 提示词字符数 | 按长短找 |
| `line` | 压缩文件中的行号 | 回读 |
| `head` | 前 80 字 | 快速判断是否相关 |

### video-prompt-library

```json
{
  "id": "VPL-sd2-240",
  "zone": "主库",
  "model": "Seedance 2.0",
  "cat": "微距·FPV特写",
  "sub": "动物·生灵",
  "name": "蜻蜓·毒气温室生死突围",
  "desc": "超广角微距FPV跟拍蜻蜓……",
  "tags": ["微距", "FPV", "120fps", "昆虫", "慢动作"],
  "lang": "zh",
  "length": 830,
  "line": 1,
  "head": "超广角微距FPV跟拍镜头紧锁一只昆虫界的终极战斗机……"
}
```

| 字段 | 含义 | 可用来筛 |
|---|---|---|
| `zone` | 主库 / 通用区 / 教程区 | 先分区 |
| `model` | Seedance 2.0 / 2.5 / 可灵 / 海螺 / 空 | 按模型 |
| `cat` / `sub` | 题材或词典分组 | 按类 |
| `tags` | 3–6 个标签 | 按关键词 |
| `name` / `desc` | 中文标题与简介 | 快速判断 |
| `lang` | `zh` / `en` | 按语言 |
| `length` | 原文字符数 | 按长短 |

## 3. 命令行工具

### 统计

```bash
python tools/kb.py stats
```

### 搜索

```bash
# 关键词（搜 head / project / cat / model）
python tools/kb.py search --keyword "雨夜" --limit 10

# Higgsfield：某项目里的分镜视频提示词
python tools/kb.py search --project DETOUR --cat scenes --type video --limit 10

# Higgsfield：Seedance 2.5 的长提示词
python tools/kb.py search --model seedance_2_5 --min-length 2500 --limit 10

# Higgsfield：自动模型、很短的镜头描述
python tools/kb.py search --model default --max-length 400 --limit 10

# VPL：主库里的动作打斗
python tools/kb.py search --source vpl --zone 主库 --cat "动作·打斗" --limit 10

# VPL：通用区运镜词典
python tools/kb.py search --source vpl --zone 通用区 --cat "运镜词典" --limit 10

# 按标签
python tools/kb.py search --source vpl --tags "微距,FPV" --limit 10
```

输出为 TSV，一行一条：

```text
HFX-DETOUR-000123	Higgsfield	DETOUR	scenes	video	seedance_2_5	7216	...
VPL-sd2-240	VPL	主库/微距·FPV特写/动物·生灵	Seedance 2.0	830	...
```

### 取全文

```bash
python tools/kb.py get --id HFX-DETOUR-000123
python tools/kb.py get --id VPL-sd2-240
python tools/kb.py get --id HFX-DETOUR-000123 --json
```

`get` 会按 ID 解析项目与行号，打开对应的 `prompts.jsonl.gz`，打印完整提示词。`--json` 输出原始对象。

## 4. 没有 Python 时

### 用 ripgrep 搜索引

```bash
rg -n "雨夜" catalog/higgsfield-prompts.index.jsonl
rg -n '"project":"DETOUR"' catalog/higgsfield-prompts.index.jsonl
rg -n '"cat":"动作·打斗"' catalog/video-prompt-library.index.jsonl
```

### 按行号回读

Bash：

```bash
python -c "import gzip;print(gzip.open('sources/higgsfield/prompts/DETOUR/prompts.jsonl.gz','rt',encoding='utf-8').readlines()[122])"
```

PowerShell：

```powershell
python -c "import gzip;print(gzip.open(r'sources\higgsfield\prompts\DETOUR\prompts.jsonl.gz','rt',encoding='utf-8').readlines()[122])"
```

### 取出 JSON 字段

```bash
python -c "import gzip,json;print(json.loads(gzip.open('sources/higgsfield/prompts/DETOUR/prompts.jsonl.gz','rt',encoding='utf-8').readlines()[122])['prompt'])"
```

## 5. 常用筛选策略

| 想找 | 怎么筛 |
|---|---|
| 同一场戏的连续镜头 | 先按 `project` + `cat=scenes`，再按 `line` 看相邻行 |
| 同题材但不同片 | 按 `cat` + `type`，再跨 `project` 看 `head` |
| 某模型的写法 | 按 `model`，再按 `cat` 分层 |
| 很短的镜头描述 | `--max-length 400` |
| 很长的完整段落 | `--min-length 3000` |
| 英文原文 | VPL `lang=en`；Higgsfield 多数项目为英文 |
| 自动模型 / 未指定模型 | `--model default` |
| 带官方简报的项目 | 看 `sources/higgsfield/projects/<项目>/brief.txt` 或 `brief全文.txt` |

## 6. 行号会变吗

会。源文件增删后，`line` 会变化。规则：

- 引用时用 `id`，不要只记行号。
- 批量取用前先重跑 `python tools/build_catalog.py`。
- 如果 `get` 报“第 N 行不存在”或内容对不上，说明源文件变了，重建索引再取。

## 7. 检索的边界

- 索引的 `head` 只是前 80 字，不能代替原文判断。
- `len` 是字符数，不是 token 数；中文与英文的实际 token 比例不同。
- `model` 字段来自上游记录，`default` 表示平台自动选择，不是某个具体模型。
- Higgsfield 一条记录可能同时包含多个镜头，不要假设“一行 = 一个镜头”。
- 项目内去重、跨项目不去重；同一句在两个项目出现是两条记录。

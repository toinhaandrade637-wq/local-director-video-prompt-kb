# 字段与格式

> 读任何文件前，先确认它属于哪种格式。不同来源的字段不一样，不要混用。

## 1. 通用约定

- 所有文本文件为 **UTF-8**。
- JSONL：一行一个 JSON 对象，行内不换行；空行忽略。
- 提示词原文里的换行在 JSON 字符串中以 `\n` 或 `\r\n` 转义，解析后还原。
- 时间、模型名、分类名保留上游原样，不做静默改写。
- 稳定 ID 一旦生成不再变化；行号会随源文件增删变化。

## 2. Higgsfield 全量语料：`prompts.jsonl.gz`

路径：`sources/higgsfield/prompts/<PROJECT>/prompts.jsonl.gz`

### 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `id` | string | `HFX-<PROJECT>-<六位>` |
| `cat` | string | `scenes` / `characters` / `locations` / `props` / `assets` / `cover` / `all` |
| `type` | string | `video` / `image` / 空 |
| `model` | string | 模型标识，如 `seedance_2_5`；`default` 为平台自动 |
| `prompt` | string | **提示词全文** |

### 一行示例

```json
{"id":"HFX-DETOUR-000001","cat":"scenes","type":"video","model":"seedance_2_5","prompt":"Suspenseful action vibe..."}
```

### 类别怎么理解

| cat | 里面通常是什么 | 怎么写进创作 |
|---|---|---|
| `characters` | 角色外观、服装、年龄、气质 | 建立角色设定与参考分工 |
| `locations` | 场景、空间、光线、天气 | 建立场景设定 |
| `props` | 道具、车辆、武器、产品 | 建立道具设定 |
| `scenes` | 分镜、镜头、场面调度 | 学叙事顺序与镜头密度 |
| `assets` | 图生视频素材、重跑、局部修改 | 学资产迭代，不直接当分镜 |
| `cover` | 封面、海报 | 学主视觉 |
| `all` | 只在全量文件里出现、未归类的提示词 | 兜底检索；量最大 |

### 项目级附属文件

| 文件 | 内容 |
|---|---|
| `sources/higgsfield/projects/<项目>/README.md` | 项目文件清单、条数、模型分布 |
| `sources/higgsfield/projects/<项目>/brief.txt` | 官方项目简报（部分项目有） |
| `sources/higgsfield/projects/<项目>/brief全文.txt` | 05 区整理的完整简报（部分项目有） |
| `sources/higgsfield/projects/<项目>/SKILL.md` | 官方 Skill（部分项目有） |
| `sources/higgsfield/projects/<项目>/official_skills/` | 官方 Skill 附件（部分项目有） |
| `sources/higgsfield/_项目元数据.json` | 项目主题、作者、原链接、语言 |
| `sources/higgsfield/_项目总索引.md` | 上游 78 项目索引（历史版本） |

## 3. video-prompt-library：`AI-全库.jsonl`

路径：`sources/video-prompt-library/AI-全库.jsonl`

### 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| `区` | string | `主库` / `通用区` / `教程区` |
| `id` | string | 原库 ID，如 `sd2-240` |
| `model` | string | 模型名，如 `Seedance 2.0`；通用区多为空 |
| `cat` | string | 一级分类，如 `动作·打斗`、`运镜词典` |
| `sub` | string | 二级分类，如 `近身·格斗` |
| `name` | string | 中文标题 |
| `desc` | string | 中文简介 |
| `tags` | string[] | 3–6 个标签 |
| `lang` | string | `zh` / `en` |
| `original` | string | **逐字原文**，不可改写 |
| `zh` | string | 英文条目的中文译文；中文条目为空 |
| `src` | string | 来源说明 |
| `title` / `steps` | string / array | 教程区专用 |

### 读法

- 写中文提示词：读 `original`；英文条目再参考 `zh`。
- 学结构：先看 `cat` / `sub` / `tags`，再读 `original`。
- 教程区：读 `title` + `steps`，不要把它当单条提示词。

## 6. 本库索引格式

### `catalog/higgsfield-prompts.index.jsonl`

- `id` = `HFX-<project>-<六位 line>`。
- `line` 是 1-based，指向对应项目压缩文件。
- `head` 是压缩空白后的前 80 字。

### `catalog/video-prompt-library.index.jsonl`

- `id` = `VPL-<原 id>`。
- `zone` / `cat` / `sub` 保留原值。
- `head` 取 `original` 前 80 字。

### `index.json`

机器可读总表：

```json
{
  "schema_version": "2.0",
  "name": "...",
  "updated": "YYYY-MM-DD",
  "counts": {},
  "entrypoints": {},
  "sources": [],
  "stats": {}
}
```

## 7. 命名与路径规则

| 对象 | 规则 |
|---|---|
| 目录 | ASCII，短横线分隔，如 `seedance-2.5` |
| 文档 | 中文名可以，但保持稳定，不随意改 |
| 索引 ID | 大写来源前缀 + 稳定标识 |
| 源文件 | 不改名、不挪动；需要整理时改索引，不改原文 |
| 新增项目 | 放 `sources/higgsfield/prompts/<PROJECT>/prompts.jsonl.gz` + `sources/higgsfield/projects/<PROJECT>/` |

## 8. 不要做的事

- 不要把 `original` 改成“更顺”的版本。
- 不要把 `zh` 译文回填进 `original`。
- 不要把不同来源的同名字段当成同一含义（例如 VPL 的 `cat` 与 Higgsfield 的 `cat`）。
- 不要手改 `catalog/*.jsonl`；改源文件后重跑生成脚本。

## 5. 已知限制

这些不是错误，是数据本身的边界：

| 限制 | 影响 | 应对 |
|---|---|---|
| 537 个项目只有 `all` | `--cat scenes` 常返回 0 | 去掉 `--cat`，或先看项目分类覆盖 |
| 只有 6 个项目有 `scenes` 细分 | 不能按镜头类型跨全库筛 | 用关键词 + 项目名组合 |
| `model=default` 45,467 条 | 无法判断具体模型 | 只学结构，不推断能力 |
| 模型名为上游原样 | 同一模型有多种写法 | 检索用小写片段，不写死 |
| 7 处上游文档指向本机路径 | 在 GitHub 上点不开 | 原文保留，不作改写 |
| 3 个官方 Skill 引用 `image_1` 占位 | 非文件链接 | 属官方模板输入位，保留 |
| P020 原图未入库 | 文档中的图片链接失效 | 只保留文字转录，原图在本地 |
| 78 项目仓 JSONL 未单独保留 | 旧链接会失效 | 已被 611 项目全量覆盖，见 `sources/higgsfield/_INDEX.md` |

## 6. 复现

```bash
# 重建索引与统计
python tools/build_catalog.py

# 完整校验（含 611 个项目逐项核对，约 1 分钟）
python tools/validate_kb.py

# 快速校验（CI 用，跳过逐项目压缩文件）
python tools/validate_kb.py --fast

# 抽查检索
python tools/kb.py stats
python tools/kb.py search --project DETOUR --cat scenes --limit 3
python tools/kb.py get --id HFX-DETOUR-000166
```

## 7. 环境

- Python 3.9+，只用标准库。
- 无需安装依赖。
- 语料读取用 `gzip` + `json`，索引读取逐行流式处理，内存占用低。

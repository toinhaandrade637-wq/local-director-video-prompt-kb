## 3. 公开决定

第三个来源（Seedance 2.5 知识库）与通用技能仓原为私有库。用户在本轮明确要求把它们并入公开的配套知识库，因此按原样收录。

收录前做了以下处理：

- 去掉 `.git`、`.github`、`.mimosa` 运行时缓存。
- 扫描并排除令牌、密钥、私钥、邮箱等敏感信息。
- 文档中的本机绝对路径不改写原文，但新增说明文件不写死路径。

如果上游权利人不同意公开，按 `NOTICE.md` 的下架流程处理。

## 4. 版权口径

| 内容 | 权利归属 | 本库态度 |
|---|---|---|
| 原始提示词 | 原作者 / Higgsfield 平台 | 只做学习与检索，不主张著作权 |
| 官方教程、博客、brief | Higgsfield 与对应创作者 | 文本存档，注明来源 |
| 方法与知识库正文 | 原知识库作者 | 保留原文与署名链接 |
| 技能包 | 原技能作者 | 保留 `SKILL.md` 与来源 |
| 本库说明、索引、工具 | 导演工作组 | MIT（见 `LICENSE`） |

## 5. 准确性声明

- 语料来自公开页面与既有整理，**不保证每条提示词都经过生成验证**。
- `model` 字段保留上游原样：`default` 表示平台自动选择，不是具体模型。
- `type` 由模型名推断，空值表示无法判断。
- `cat` 由源文件名推断，可能与内容不完全一致。
- 计数由脚本从文件重新计算；数字与 `index.json` 不一致时，以文件为准并重跑构建。

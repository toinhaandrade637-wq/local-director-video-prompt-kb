# 快速开始

## 场景 A：我想找一条能参考的提示词（5 分钟）

1. 打开 [catalog/video-prompt-library.md](../catalog/video-prompt-library.md)，看主库/通用区/教程区哪一类对得上。
2. 记下分类名，例如“动作·打斗”“运镜词典”。
3. 用一条命令检索：

```bash
python tools/kb.py search --source vpl --cat "动作·打斗" --limit 10
python tools/kb.py get --id VPL-sd2-259
```

也可以直接搜 `catalog/video-prompt-library.index.jsonl`，拿到 `line`，再读 `sources/video-prompt-library/AI-全库.jsonl` 对应行。

## 场景 B：我想学一部片子的完整提示词工程（15 分钟）

1. 在 [Higgsfield 项目总表](../catalog/higgsfield-projects.md) 按主题找到项目。
2. 打开 `sources/higgsfield/projects/<项目>/README.md`，看文件构成、模型分布、有没有 brief / official_skills。
3. 先读 `brief.txt` 或 `brief全文.txt`（若有），理解项目目标与风格。
4. 用 `cat` 分层看：
   - `characters`：角色设定
   - `locations` / `props`：场景与道具
   - `scenes`：分镜/镜头
   - `assets`：图生视频的镜头资产与重跑
5. 如果 `scenes` 没有结果，说明这个项目只有 `all`（537 个项目如此），去掉 `--cat` 再查。
6. 不要一次读完整个项目。按 `catalog` 索引定位，读 5–10 条代表作即可。

```bash
python tools/kb.py search --project DETOUR --cat characters --limit 10
python tools/kb.py search --project DETOUR --cat scenes --limit 10
```

## 场景 C：我要写一条新提示词（30 分钟）

1. 读 [Seedance 2.5 通用结构](../sources/seedance25-knowledge-base/现行知识/02-通用结构与选用.md)。
2. 读 [Higgsfield 视频 01 提示词结构](../sources/higgsfield-knowledge-base/现行知识/视频/01-提示词结构.md)，补块语法与配时。
3. 按任务补 1–2 页方法（对白→SD25 05，打戏→SD25 06 + HF 04，运镜→HF 03，光影→SD25 08）。
4. 用 `tools/kb.py search` 找 2–5 条同题型参考。
5. 按“生成目标 → 参考分工与全局设定 → 按镜头/阶段的小段 → 结束状态与约束”写。
6. 用 [AGENTS.md](../AGENTS.md) 第 6 节的自检清单过一遍。
7. 末尾附参考来源与待确认项。

## 场景 D：让 AI 直接接手


## 常见误区

| 误区 | 正确做法 |
|---|---|
| 解压所有项目从头读 | 先用 `catalog` 索引定位到具体行 |
| 把参考提示词整段复制 | 只迁移结构与镜头关系，事实全部替换 |
| 看到一条很长的提示词就当成标准 | 先看它的模型、类别、项目目标，再判断是否适用 |
| 用索引摘要当原文 | 摘要只用于筛选，写作前必须回读原文 |
| 把 78 项目仓当全量 | 611 项目全量语料才是完整版 |
